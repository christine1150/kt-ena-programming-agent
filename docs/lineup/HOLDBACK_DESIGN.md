# 라인업 홀드백(자사 채널 방영 가능 일시) — 구현 기록

작성 2026-11-25, 같은 날 구현. 사용자 요청: "홀드백을 알려주면, 나머지 채널들도 선택했을 때 편성 가능한 일시가 나오게 하자."

## 1. 규칙(사용자 전달) — `src/lib/lineup/holdbackRules.ts`

기준: ENA 본방 한 회가 **끝난 시각**(예: 22:00~22:51 방송이면 22:51)부터 + 채널별 대기일 뒤에 그 채널에서 방영할 수 있다.

| 작품 | 규칙 |
|---|---|
| 니돈내산 | 나머지 자사 6채널 모두 직후 |
| 카우몰(카드 한 장에 우정이 흔들리는 줄은 몰랐습니다만) | OLIFE 제외 5채널 직후 |
| 결이 다른 전쟁사 | ENA Drama 직후(매주) · ENA Play·Story·OLIFE·ONCE·skyUHD는 매 회 4주(28일) 후 |
| 맡겨만 주십숏(9/25~10/16, 4회) | 직후 재방은 ENA Play만 · 나머지 채널은 각 회 4주 후 |
| 오리지널 드라마(지금부터 방영) | 나머지 6채널 모두 직후(기본 규칙) |

- 규칙 목록에 없는 작품은 계산하지 않는다(추정 금지).
- 규칙은 코드 상수(channelEligibility.ts·followRule.ts와 같은 방식)라 **DB 변경이 없다**. 초안의 `lineup_holdbacks` 표는 만들지 않았다. 규칙이 늘어 관리자가 직접 입력해야 하면 그때 표로 옮긴다.
- 맡겨만 주십숏은 '그 외 모든 채널 7개'라고 하셨으나 ENA 자신의 재방은 계산하지 않았다(확인 대기).

## 2. 계산 — `holdback.ts`(순수 함수) · `holdbackMinutes.ts`(서버)

- 이미 방송된 회차: 실제 방송 기록(ratings 닐슨 일별)의 같은 자리 종료 시각을 분 단위로 **올림**해 쓴다(예: 23:51:58 → 23:52).
- 아직 방송 전인 회차: 같은 작품 같은 자리 방송 길이의 중간값(분)을 자리 시작 시각에 더한다. 방송 기록이 전혀 없으면 시각은 비우고 날짜만 보인다.
- 자정을 넘기면 다음 날 날짜로 계산한다. 결방·휴방 회차는 센 뒤 빼지 않고 건너뛴다(회차 순번은 첫방부터 자리 요일 센 값).

## 3. 화면

캘린더 위쪽 **'방영 가능 일시 보기'**: [안 봄] + 자사 6채널(ENA 제외) 중 하나를 선택. 선택하면 그 채널이 방영 가능해지는 날짜 칸에 점선 `◇ 23:14~ 작품 N회` 표식이 붙고, 날짜를 누르면 오른쪽 패널에 '방영 가능 시작' 목록이 나온다. 주소 `can=ENA_PLAY`. 저장·인쇄 창에도 같은 선택이 있어 PDF·엑셀에 반영된다.

## 4. 알려진 차이·확인 대기

- 사용자 전달값 '결이 다른 전쟁사 ENA Play 11/20(금) 23:50 이후'와 계산 23:52(실제 종료 23:51:58 올림)는 2분 차이 — 사용자 값은 편성표상 시각으로 보인다. 실제 종료 기준(안전)으로 계산했다.
- '결이 다른 전쟁사 ENA Drama 10/25(일) 23:50 이후'는 규칙대로면 첫 회 ENA 방송(10/23 금) 직후인 10/23 23:52다. 날짜가 10/25로 적힌 이유는 확인이 필요하다.
