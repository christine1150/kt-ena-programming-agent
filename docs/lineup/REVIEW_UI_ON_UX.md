# 라인업 화면 — UX 설계안에 대한 UI 교차 검토

- 작성: 2026-11-24 · 작성 역할: UI 디자이너 · 검토 대상: `docs/lineup/UX_PLAN.md`(UX 아키텍트) · 비교 기준: `docs/lineup/UI_DESIGN.md`(UI 디자이너)
- 판단 기준: **가독성**(한눈에 읽히는가, 뜻이 하나인가), **인쇄**(흑백·A4/A3에서 살아남는가), **구현 복잡도**(한 번 그리면 끝나는가, 같은 것을 두 번 만들지 않는가).
- 이 문서는 두 설계안을 고치지 않는다. 합의안을 적용할 때 각 문서에서 고칠 곳은 §5에 모았다.
- 대외비: 예시는 모두 가명(`자사 드라마 A`, `타사 가 주말극 1`)이고, 원자료의 제목·주연·제작사는 쓰지 않았다.

## 1. UX 질문 Q1~Q12 답변

| # | 질문 요지 | 답(UI 디자이너) | 근거 |
|---|---|---|---|
| **Q1** | 드라마 색: `--chart-4` 유지 vs 원자료 분홍에 가까운 새 토큰 | **`--chart-4`(#a21caf)를 유지하고 새 토큰은 만들지 않는다.** 막대 바탕은 이 색을 흰색과 12% 섞은 `#f4e4f5`라 화면에서는 이미 "옅은 분홍"으로 읽힌다. 진한 색은 왼쪽 띠·테두리에만 쓴다. | 분홍 계열(pink-500 `#ec4899`)은 흰 글자 대비 3.5:1로 기준(4.5:1) 미달이고, 단계 15 토큰 검사(`test-ui-polish.ts`) 밖의 색이 하나 더 생긴다. 참고로 UX안의 "흰 글자 약 6.5:1"은 실측 **6.32:1**이다. 기준은 넘는다. |
| **Q2** | 추정 끝(옅은 꼬리 + 점선 끝 ╌▸)이 흑백·저대비에서 구분되는가 | **그라데이션 꼬리만으로는 흑백·저대비 화면에서 구분되지 않는다.** 그래서 세 가지를 함께 쓴다. ① 마지막 1주 폭을 채움 그라데이션으로 흐리게 한다(장식 층 `mask-image`). ② 추정 끝 위치에 1.5px 점선 세로선을 긋는다. ③ 날짜 글자 앞에 `≈`(예: `≈3/13`)를 붙인다. **화살표 머리(▸)는 빼고** `→ 계속`에만 남긴다. | 흑백 출력에서는 그라데이션이 회색 얼룩이 된다. 남는 단서는 점선 끝과 `≈` 글자다. 화살표가 두 뜻(추정 끝·계속 방송)을 갖지 않게 한다. |
| **Q3** | 월 단위 범위 괄호(├────┤)가 막대가 아님이 읽히는지, 제목 위치 | **괄호안에 찬성한다.** UI안의 양 끝을 흐리게 하는 방식은 철회한다(§2-4). 모양: 장르색 2px 가로선과 양 끝 8px 세로 눈금, 줄 아래쪽에 둔다. **제목은 괄호 위**(13px 굵게) + `월 단위` 칩. 누름 영역은 범위 폭 × 줄 높이 전체. | 방송사 캡처 자료는 "1~2월", "2~3월"처럼 **범위끼리 겹친다**. 흐린 막대를 겹치면 지저분하지만, 괄호는 한 줄 안에 두 칸(각 20px)으로 쌓아도 읽힌다. 흑백에서도 선과 눈금은 그대로 남는다. |
| **Q4** | 넉넉 보기 2줄째 "기간 · 회차 · 주연" 순서와 기호 | 1줄: **제목 + 오른쪽 `12회` 칩**(들어갈 때). 2줄: **기간 · 주연**. 회차가 1줄에 안 들어가면 2줄 기간 뒤로 옮긴다. 공간이 줄면 주연 → 회차 순으로 빼고, 기간은 2줄이 있는 한 남긴다. 구분 기호는 앞뒤 띄운 가운뎃점(` · `). | 회차는 짧고 판단에 중요하다(12회냐 16회냐). 주연은 막대 폭이 280px 이상일 때만 의미 있게 들어간다. |
| **Q5** | 경쟁 비교 자사 줄 강조: 브랜드색 채움 / 왼쪽 띠 / ★ | **왼쪽 3px 띠(`#3C32E1`) + 행 머리 연보라 바탕(`#ECEBFD`, 굵은 `#3C32E1` 글자 6.53:1) + 격자 줄 아주 옅은 바탕(`#f7f7fe`).** ★은 쓰지 않는다. **막대를 브랜드색으로 칠하지 않는다.** | 이 셋은 시청률 표(`/ratings`)의 자사 행 모양과 같다. 막대 채움은 장르 전용이다(§2-6). ★은 기호가 하나 더 늘어날 뿐이고, 고정 위치(묶음 맨 위)가 이미 자사임을 말해 준다. |
| **Q6** | 맞대결 초점: 흐린 정도·세로 띠 색 | **흐리기는 요소 전체에 `opacity`를 걸지 않는다.** 장식 층(채움·테두리)만 `opacity-40`으로 하고 제목 글자는 `--text-tertiary`(#52525b)로 바꾼다. 세로 띠는 선택 윤곽과 같은 파랑 계열 `--focus-ring` 6%(`bg-[#1d4ed8]/[0.06]`)에 양쪽 1px 경계(`#1d4ed8` 30%). 브랜드 파랑(`#3C32E1`)은 자사 줄 전용이라 쓰지 않는다. | 요소 전체 `opacity-35`는 글자 대비를 약 2.3:1로 떨어뜨린다. 흐려진 막대도 누를 수 있으니 WCAG 1.4.3 예외가 아니다. UI안의 같은 규정(`opacity-35`)도 이렇게 고친다. |
| **Q7** | 접힌 묶음 요약 줄 눈금: 장르색 vs 회색 하나 | **장르색, 단 장르마다 고정 위치의 가는 줄**(드라마 위·예능 가운데·사업형 아래, 각 6px). | 회색 하나로 하면 "회색 = 작품 정보 없음" 규칙과 부딪힌다. 위치가 고정이라 흑백에서도 어느 장르인지 읽힌다. |
| **Q8** | 범례 위치·첫 방문 펼침 | 도구줄 아래 한 줄에 고정하고 접을 수 있게, **첫 방문에는 펼쳐 둔다**(접힘 상태는 `localStorage`, 실패하면 무시). **두 단계 범례**로 나눈다. 기본 7개(장르 4 · 실선 확정 / 점선 예정 · 미정 · 빗금 휴방·결방 · 오늘선)만 늘 보이고, 나머지(◆ 단발 · 월 1회 · 월 단위 괄호 · 추정 끝 · 수급 · 계속 · 바뀜 · 빈 주 · OTT 칩)는 `더 보기`. | UX안 범례를 한 줄에 다 두면 1280px에서 2~3줄로 꺾인다. 기호 20여 개를 늘 보여 주면 범례가 격자보다 시끄러워진다. |
| **Q9** | 줄 높이 44/28px, 제목 13px·보조 12px, 1년 확대에서 12px 미만이 필요한지 | **44/28px에 찬성한다**(막대 높이 36/24px로 UI안을 고친다). 글자는 **화면 어디서도 12px 아래로 내리지 않는다.** 1년 보기에서 안 들어가는 제목은 바깥 라벨 → 줄임말 → 표식+툴팁으로 처리하고, 인쇄에서는 번호 각주를 쓴다. | 앱 글자 바닥 규칙(12px, `globals.css` 단계 15)과 같다. 격자에 `.dense-grid`를 붙이면 이 자동 보정에서도 빠지므로 **스스로 지켜야 한다**. 촘촘 막대 24px는 누름 영역 최소값(`--target-min`)과 같다. |
| **Q10** | 월 1회 점 지름·연결선 굵기, 28px 줄에서 누르기 쉬운지 | 보이는 점 10px(흰 2px 테두리 `ring-2 ring-white`), 연결선은 2px **점선**(실선은 "연속 편성"처럼 읽힌다). 점마다 24×24 투명 누름 영역을 둔다. 28px 줄 안에 들어간다. | 1년 보기(주 20px 남짓)에서도 월 1회 점 사이는 약 80px라 누름 영역이 겹치지 않는다. |
| **Q11** | 인쇄 각주: 동그라미 숫자 vs 작은 숫자 꼬리표, 몇 단 | **작은 숫자 꼬리표**(1px 테두리 상자 안 숫자, 8pt). 각주는 **쪽 아래가 아니라 각 묶음(블록) 끝에** 둔다. A4는 3단, A3는 4단. | 동그라미 숫자는 ⑳에서 끝나고 글꼴마다 모양이 다르다. 브라우저 CSS로는 "그 쪽의 아래"에 각주를 놓을 수 없다(쪽 나눔 위치를 알 수 없음). 묶음은 쪽 사이에서 잘리지 않게 하므로(`break-inside: avoid`) 묶음 끝 각주는 같은 쪽에 남는다. |
| **Q12** | 상세 패널 400px가 1280px 노트북에서 격자를 가리는지 | **화면 폭에 따라 나눈다.** 1536px 이상: 격자를 밀어내는 방식(`pr-[416px]`), 패널 400px. 1280~1535px: 덮개 방식, 패널 **360px**, 고른 막대가 가려지면 격자를 옆으로 밀어 보이는 범위로 데려온다. 1280px 미만: 덮개 360px. 맞대결 요약은 **같은 패널 안의 한 구역**으로 넣고 오른쪽 패널을 두 개 열지 않는다(§3-7). | 1280px에서 격자에 쓸 폭은 약 1048px이다. 400px를 덮으면 38%가 가려진다. 패널 두 개(맞대결 요약 + 상세)는 격자를 절반 아래로 줄인다. |

## 2. 두 설계안의 충돌과 권고

### 2.1 한눈에

| # | 쟁점 | UI안 | UX안 | **권고** | 가독성 | 인쇄 | 구현 |
|---|---|---|---|---|---|---|---|
| 1 | 시간 축 | 주 칸(월요일 시작)에 맞춘 막대 | 하루 단위 달력 축, 막대는 실제 방송 요일 위치 | **하루 단위 축(UX) + "자리 점유" 끝 규칙 + 최소 폭 24px**(§2.2) | 두 안의 장점을 합침 | 같음 | 서버 순수 함수 하나 추가 |
| 2 | 확대 단계 | 3단(3개월/6개월/1년) = 기간 길이 | 4단(주/월/분기/1년) + 기간 고르기 + 화면 맞춤 켜고 끄기 | **조작 하나로 합친다: "보는 길이" 4단(3개월 · 6개월 · 8개월(기본) · 1년), 화면 맞춤은 항상 켬, 최소 주 폭 아래면 가로 밀기.** 올해·내년·상반기·하반기는 `기간 ▾` 메뉴의 바로가기 | 조작 세 개(길이·확대·맞춤)가 서로 무엇을 덮는지 사용자가 알 수 없다 | 같음 | 상태 조합이 줄어 주소 쿼리도 단순해짐 |
| 3 | 블록 묶음 | 월화 / 수목 / 금토 / 토일 / 그 밖 | 월화 / 수목 / 주말(금·토·일 합침) / 기타 | **UX의 4묶음(주말 하나).** 단 줄 머리 맨 앞에 **고정 폭(36px) 요일 칩**(`금`·`금토`·`토일`)을 두어 세로로 줄을 맞추고, 주말 안에서는 요일 칩 순 → 방송사 순 | 금토극과 토일극은 토요일 밤에 실제로 맞붙는다. 묶음을 나누면 맞대결이 다른 블록으로 갈라진다 | 묶음이 하나 줄어 쪽 나눔이 단순 | 같음 |
| 4 | 월 단위 날짜 | 막대 양 끝 흐림 | 막대를 그리지 않고 범위 괄호 | **괄호(UX)**(Q3) | 범위가 겹쳐도 읽힘 | 선·눈금이 흑백에서 남음 | 마스크보다 단순 |
| 5 | 첫 방송일만(끝 추정) | 끝 1주 흐림 + `≈` | 옅은 꼬리 + 점선 끝선 ╌▸ | **흐림 + 점선 끝선 + `≈`, 화살표 없음**(Q2) | 화살표 한 뜻 | 점선·`≈`가 남음 | 같음 |
| 6 | 타사 막대 색 | 장르색(자사와 같은 문법) | 회색 하나(`--surface-muted` 채움 + `--border-control` 테두리) | **장르색(UI).** 자사·타사는 줄 위치와 줄 강조로 나눈다 | UX안은 회색 타사 막대·회색 수급물·회색 기타·회색 공휴일 음영이 한 화면에 모여 **옛 화면의 "회색 혼동"을 경쟁 비교에서 되살린다** | 흑백에서 회색 막대·수급물·미정이 테두리 점선 하나로만 갈린다 | 같음 |
| 7 | 예능 색 | `--chart-5`(청록) | `--chart-1`(파랑) | **청록(UI)** | 파랑은 자사 줄 강조·보기 탭·선택 윤곽이 이미 쓴다. "파랑 = 장르"와 "파랑 = 자사·선택"이 겹친다 | 차이 없음 | 같음 |
| 8 | 기타 장르 색 | `--chart-3`(초록) | `--chart-6`(회색) | **초록(UI)** | 회색은 "작품 정보 없음" 전용이어야 혼동이 없다 | 같음 | 같음 |
| 9 | 확정 정도 표현 | 테두리: 실선 = 확정 / 점선 = 예정, 채움은 늘 옅게 | 진하기: 확정·예정 = 꽉 찬 채움 / 가안 = 옅은 채움 + 실선 테두리 | **테두리 문법(UI)**, 가안·가제는 점선 + 제목 뒤 `(가제)` 글자 | 옛 화면 범례가 이미 "예정 = 점선"이라 익숙하다. UX안은 확정과 예정이 **같은 모양**이 되어 구분이 사라진다. 옅은 채움 위 진한 글자는 대비 14:1대, 진한 채움 위 흰 글자는 5~6:1대 | 진한 채움이 많으면 토너가 많이 들고 빗금·괄호·오늘선이 묻힌다 | 같음 |
| 10 | 막대 글자 줄 수 | 막대 안 최대 2줄, 넘치면 바깥 라벨 → 줄임말 → 앞 글자 → 표식 | 막대 안 2줄 + 막대 **아래 글자 줄**(줄 높이 16px 증가) + 사람이 정한 줄임말 → … | **막대 안 최대 2줄, 아래 글자 줄은 쓰지 않는다.** 줄임말은 사람이 정한 `short_title`을 먼저, 없으면 `shortProgramName`. 마지막 수단의 "…"는 두 안 모두 허용 | 아래 줄은 확대·기간을 바꿀 때마다 줄 높이가 달라져 격자가 출렁이고, 이어지는 두 막대의 아래 글자끼리 붙어 어느 막대 것인지 헷갈린다(UX안 §2.2 와이어프레임의 `10/12~11/17 · 12회    11/23~12/29 · 12회`) | 인쇄는 번호 각주(UX)로 해결 | 줄 높이가 고정이면 묶음·인쇄 계산이 쉬워진다 |
| 11 | 기본 기간 | 6개월(이번 달부터) | 8개월(지난달 ~ 6개월 뒤) | **8개월(UX)**, 단 A4 인쇄 기본은 6개월 | 지금 방영 중인 작품의 시작이 보인다(P1-1) | 6개월은 A4 주 폭 35px, 8개월은 26px | 같음 |

### 2.2 시간 축 — 하루 단위 축 + "자리 점유" 끝 규칙 (충돌 1 자세히)

**UX안이 맞는 점.** 첫 방송 맞대결(P1-3)이 가장 중요한 질문이다. 주 칸에 맞추면 토요일(11/14)에 시작한 타사 주말극이 그 주 월요일(11/9) 칸부터 그려진다. 그러면 월요일(11/16)에 시작한 자사 월화극보다 **한 주 먼저** 시작한 것처럼 보이는데, 실제 차이는 이틀이다. 업계 종합본은 섹션마다 주 머리의 요일도 다르다. 그래서 하나의 하루 단위 축이 정직하다.

**UI안이 걱정한 점(그대로 두면 생기는 문제).** 8개월 맞춤(1440px)에서 하루는 약 5px, 한 주는 약 35px이다.
- 월화극이 화요일에 끝나고 다음 작품이 다음 주 월요일에 시작하면, 실제 날짜대로 그릴 때 사이에 **5일(약 25px) 빈 틈**이 생긴다. 실제로는 결방이 없는데 "한 주 비었다"처럼 보인다. 토일극 사이도 같다(월~금 5일).
- 월화 2회짜리 특집(1주)을 실제 날짜대로 그리면 이틀, 약 10px이다. 글자도 못 넣고 누름 영역 24px에도 못 미친다.

**권고: 축은 하루 단위, 막대의 보이는 끝은 "자리 점유" 기준.**

| 항목 | 규칙 |
|---|---|
| 시작 | 정확일이면 첫 방송일 위치. 주 단위 자료면 그 주의 블록 첫 요일(UX §8.2 메모와 같음) |
| 보이는 끝 | 마지막 방송일에서 **그 자리의 다음 정규 방송 요일 전날**까지 늘려 그린다. 월화 자리는 마지막 화요일 → 그 주 일요일, 토일 자리는 마지막 일요일 → 다음 금요일, 주 1회 수요일 자리는 마지막 수요일 → 다음 화요일. 결과: 이어지는 작품은 2px 틈만 두고 붙고, **정말 비는 주만 한 주 폭 이상 빈다** |
| 최소 폭 | 보이는 폭이 24px보다 짧으면 오른쪽으로 24px까지 늘린다 |
| 글자·패널·목록 | 실제 날짜(`11/16(월) ~ 12/22(화)`)를 쓴다. 늘린 끝은 그리기에만 쓴다 |
| 맞대결 계산 | 그리기 끝이 아니라 **실제 방송일**로 한다(UX `overlap.ts` 그대로) |
| 빈 주 계산 | 같은 규칙의 보이는 끝 다음 날부터 다음 작품 시작 전날까지를 주로 센다 |
| 계산 위치 | UX안의 `src/lib/lineupPlan/dates.ts`에 `displaySpan(run, slot)`로 둔다(서버 순수 함수, 화면은 그리기만) |

- 남는 오차: 자사 월화극의 보이는 끝(일요일)과 그 주 토요일에 시작한 타사 주말극이 그림에서 이틀 겹쳐 보인다. 실제 맞대결은 아니다. 맞대결 목록과 세로 띠는 실제 방송일로 계산하므로 판단은 틀리지 않는다. 이 오차는 주 칸 맞춤의 오차(최대 6일)보다 작다.
- 주 경계선(월요일)은 격자 안내선으로 그대로 둔다. 주 머리의 월요일 날짜 숫자도 둘 다 같다.

### 2.3 색 축 정리 (충돌 6·7·8·9·16 묶음)

두 안 모두 "색 하나에 뜻 하나"를 원칙으로 적었지만 UX안에서는 색이 보기마다 뜻을 바꾼다.

| 보기 | UX안에서 색이 뜻하는 것 | 권고 후 |
|---|---|---|
| 자사 라인업 | 장르 | 장르 |
| 경쟁 비교 | 자사 줄 = 브랜드색, 타사 = 회색 → **누구 것인가** | 장르(자사·타사 같음). 누구 것인가는 줄 위치·줄 강조·방송사 이름이 말한다 |
| 공통 | 회색 = 타사 막대·수급물·기타 장르·공휴일 음영·미정 테두리·결방 빗금 | 회색 = **작품 정보 없음** 전용(미정·수급·휴방·결방·빈 주) |

권고 후 회색 계열 세 칸은 다음처럼 모양이 모두 다르다.

| 칸 | 채움 | 테두리 | 무늬 | 글자 |
|---|---|---|---|---|
| 미정 | 흰색 | 1.5px **점선** `--border-control` | 없음 | `미정 · 12회` |
| 수급 | `--surface-muted` #f4f4f5 | 1px **실선** `--border-control` | 없음 | `OTT 수급` |
| 휴방·결방 | 흰색 | 1px 실선 `--border-control` | **빗금** | `휴방` / `결방 · 사유` |
| (빈 주, 계산값) | 없음 | 없음(1px 점선 밑줄만) | 없음 | `비어 있음 5주` |

확정 정도는 테두리로 표현한다(충돌 9).

| 상태 | 테두리 | 채움 | 글자 |
|---|---|---|---|
| 확정 | 1px 실선 장르색 | 옅은 장르색 + 왼쪽 4px 띠 | 제목 |
| 예정 | 1.5px 점선 장르색 | 같음 | 제목 |
| 가안·가제 | 1.5px 점선 장르색 | 같음 | 제목 뒤 `(가제)` |

| # | 문제 | 왜 안 되는가 | 고치는 법 |
|---|---|---|---|
| 3-1 | **표현 수가 너무 많다** | UX §5.2와 §2.3을 합치면 화면에 나올 수 있는 모양·기호가 20개를 넘는다. 막대, 점 열, ◆, ◆━◆, 빗금 칸, 빗금 조각, 점선 빈 칸, 점선 회색 칸, 옅은 채움 + 실선, 꽉 찬 채움, 범위 괄호, 옅은 꼬리 + 점선 끝, → 계속, ● 방영 중, ○ 바뀜, OTT 칩, "21:55 시작" 글자, ★ 자사, ● 시각 겹침, 빈 주 칸, 공휴일 음영, 지난 기간 바탕, 오늘선. 범례가 격자보다 시끄러워진다 | 두 단계 범례(Q8). **● 방영 중 빼기**(오늘선이 이미 말함, 목록·패널에만 글자로). **★ 빼기**(Q5). **● 시각 겹침 빼기**(흐리기로 충분, 필요하면 줄 머리에 `시간 겹침` 글자 칩). **"21:55 시작"은 넓은 막대에서만 칩**, 나머지는 패널 |

## 4. 두 안이 이미 같은 점 (그대로 간다)

- 드라마 `--chart-4`, 사업형 `--chart-2`, **사업형을 회색으로 칠하지 않음**, 판정색(`TAG_DOT_COLOR`) 미사용.
- 오늘선 `--chart-reference` 2px, 지난 기간 바탕 `--surface-subtle`(막대는 흐리지 않음).
- 월 1회 = 점(막대 아님), 단발 = ◆, 결방·휴방 = 빗금, 미정 = 흰 바탕 점선 칸.
- 막대마다 `<button>`과 `aria-label`(풀네임·기간·정밀도·회차·상태), 키보드 ←→↑↓ Enter Esc, 포커스 링 `--focus-ring`.
- 누르면 상세(400px 오른쪽 패널), 수정·보관은 권한자 단추. 끌어서 날짜 바꾸기는 없음.
- 따라붙는 제목(보이는 범위 앞에서 시작한 막대의 제목이 왼쪽 끝에 붙음). 막대에 `overflow:hidden`이 있어 CSS `sticky`가 듣지 않으므로 JS로 갱신한다.
- 풀네임 우선, 줄임말은 넘칠 때만, 전체 이름은 툴팁·패널·화면 낭독기·인쇄에서 항상 읽힘.
- 화면 맞춤(오른쪽 빈 공간 없음), 가로 스크롤 막대 숨김 + 양끝 이동 단추, 격자에 `.dense-grid`(전역 표 맞춤 규칙 회피). UI안 추가 주의: 격자 상자에 `overflow-x-auto` 클래스를 쓰지 않는다.
- 밝은 화면만(다크 모드 없음), Pretendard 계열, 표 글자 13px·보조 12px.
- 인쇄 A3 가로(1년)·A4 가로(6개월), `print-color-adjust: exact`, 대외비 표기, 흑백에서도 모양·글자로 구분.
- 휴대폰은 목록(카드)이 기본.

## 6. 요약 (핵심 충돌·권고 10줄)

1. **시간 축**: UX의 하루 단위 축을 따른다. 단 막대 끝을 "다음 정규 방송 요일 전날"까지 늘려 그리고 최소 폭을 24px로 둔다. 이어지는 작품 사이의 가짜 5일 틈과 10px 막대를 없애고, 맞대결 계산은 실제 방송일로 한다.
2. **조작 단순화**: 확대 4단·기간·맞춤 켜고 끄기를 "보는 길이 3·6·8·12개월"로 합친다. 기본 8개월(UX), 맞춤은 늘 켜고, A4 인쇄 기본은 6개월.
3. **블록**: UX의 월화/수목/주말/기타를 따른다. 금토극과 토일극은 토요일에 맞붙기 때문이다. 줄 머리 맨 앞에 고정 폭 요일 칩을 둬 주말 안에서도 줄이 정렬되게 한다.
4. **월 단위 날짜**: UX의 범위 괄호를 따른다(UI의 양 끝 흐림 철회). 범위끼리 겹쳐도 읽히고 흑백에서 남는다. 분기·반기 단위도 괄호로.
5. **타사 막대 색**: UX의 회색 대신 장르색. 회색 타사·수급·기타·공휴일 음영이 모이면 옛 화면의 "회색 혼동"이 경쟁 비교에서 되살아난다. 자사는 줄 위치·띠·옅은 바탕으로 구분한다.
6. **색 한 뜻**: 예능 청록(`--chart-5`), 기타 초록(`--chart-3`), 회색은 "작품 정보 없음" 전용(미정 흰 점선 / 수급 회색 실선 / 휴방 빗금). 브랜드색은 줄 머리 띠에만.
7. **확정 정도**: 진하기가 아니라 테두리(실선 확정 / 점선 예정·가안 + `(가제)`). UX안에서는 확정과 예정이 같은 모양이 되기 때문이다. 옛 화면의 "예정 = 점선"과도 이어진다.
8. **막대 글자**: 막대 안 최대 2줄(제목+회차 / 기간·주연), 아래 글자 줄은 없앤다. 넘치면 바깥 라벨 → 사람이 정한 줄임말 → 공식 줄임말 → 표식+툴팁. 인쇄는 묶음 끝 번호 각주.
9. **기호 정리**: ● 방영 중·★·● 시각 겹침을 빼고, ●는 월 1회 방송일, 화살표는 계속 방송, 바뀜은 접힌 모서리로 한 뜻씩만 쓴다. 범례는 기본 7개 + 더 보기 두 단계.
10. **구현·접근성**: 격자를 처음부터 `<table>` 하나로 만든다(화면 sticky, 인쇄 쪽마다 머리 반복). 흐리기는 장식 층만 하고 글자 대비 4.5:1을 지킨다. 맞대결 요약은 상세 패널 하나 안에 두고, 패널은 1536px 이상에서 격자를 밀고 그 아래에서는 360px 덮개로 한다.
