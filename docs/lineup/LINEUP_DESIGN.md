## 1. 범위

**1단계(이번 구현)**
1. `/lineup` 화면 — 보기 3개: **자사 라인업**(기본) · **경쟁 비교** · **목록**. 막대를 누르면 오른쪽 상세 패널.
2. 관리자: 같은 화면에서 막대 → 상세 패널 → 고치기·보관(지우기 대신). `/lineup/manage`에서 엑셀 업로드(미리보기 → 반영), 업로드 되돌리기, 변경 이력.
3. 업로드 양식 2종: **자사 라인업 양식**(ENA 콘텐츠 편성센터 엑셀), **업계 드라마 라인업 종합본**(블록 × 방송사, 병합 셀).
4. 전역 메뉴 "라인업" → `/lineup`.
5. 인쇄(A4·A3 가로).

**2단계(나중)**: 방송사 단독 양식·표준 양식·붙여넣기 업로드, 시청률 겹쳐 보기, 기획안 연결, PD 편집 권한, 타사 예능.

## 2. 화면 구성

```
[전역 메뉴]
┌ 라인업 ─ [자사 라인업 | 경쟁 비교 | 목록]  기간[◀ 2026.10 ~ 2027.05 ▶] 길이[3·6·8·12개월] [오늘]
│          채널[ENA ▾] 장르[드라마·예능·사업형] 요일[월…일] 밀도[넉넉·촘촘] [인쇄] (관리자: [자료 관리])
├ 자료 기준: 자사 라인업 11/06 · 업계 종합본 11/17 · 외부 편성센터 ↗        범례 7개 [더 보기]
├──────────┬───────────────────────────────────────────────────────────
│ 고정 열    │ 월 머리 / 주(월요일 날짜) 머리 / 행사·공휴일 띠      ← thead, 화면 sticky·인쇄 반복
├──────────┼───────────────────────────────────────────────────────────
│ 채널 > 장르 > 자리(요일·시각) │ 막대 …                         │ 상세 패널(400px)
```

- 주소에 상태를 남긴다: `?view=own|compare|list&from=YYYY-MM&len=3|6|8|12&ch=ENA,ENA_PLAY&genre=drama,variety&dow=1,2&density=comfy|compact&sel=<runId>`.
- 자사 라인업 행 축: **채널 묶음(A·B) > 채널 > 장르 > 자리**. 자리 라벨 = `월화 22:00`, `토 19:50`. 라인업이 없는 채널은 기본으로 숨기고 "라인업 없는 채널 N개" 한 줄로 접는다.
- 경쟁 비교 행 축: **묶음(월화 · 수목 · 주말 · 그 밖) > 자리(방송사 + 요일 칩 + 시각)**. 각 묶음 맨 위에 ENA 자리를 고정(비어 있어도 표시). 주말 안 정렬은 요일 칩(금 → 금토 → 토 → 토일 → 일) → 방송사 순. 비교 보기 기본 밀도는 촘촘.
- 목록 보기: 기간 안 구간을 시작일 순 표(시작·종료·채널/방송사·자리·제목·회차·주연·상태·출처). 휴대폰 기본 보기.

## 3. 시간 축

- **하루 단위 축** + 주 경계(월요일) 안내선. 화면 폭에 항상 맞춘다(최소 주 폭 20px 아래면 가로 밀기). 길이 3·6·8·12개월, 기본 8개월, A4 인쇄 기본 6개월.
- **보이는 끝 = 자리 점유 규칙**: 막대는 마지막 방송일에서 그 자리의 다음 정규 방송 요일 전날까지 늘려 그린다(이어지는 작품끼리 붙고, 정말 빈 주만 빈다). 최소 폭 24px. 글자·패널·목록은 실제 날짜, 맞대결은 실제 방송일로 계산.
- 오늘선: 진한 글자색 2px 세로선 + 머리에 `오늘` 칩(빨강 쓰지 않음 — 공휴일 표시와 겹치지 않게). 오늘 이전은 아주 옅은 바탕.
- 행사·공휴일 띠(thead 마지막 줄): 공휴일 = 작은 점 + 이름(`public_holidays`), 결방을 부르는 대회·시상식·선거 = 진한 칩(`lineup_events`). 설·추석 연휴만 격자에 1px 점선 세로선 두 줄.

## 4. 시각 문법(색 하나에 뜻 하나)

| 축 | 표현 | 값 |
|---|---|---|
| 장르(채움색, 자사·타사 같음) | 옅은 채움 + 왼쪽 4px 띠 + 테두리 | 드라마 `--chart-4` · 예능 `--chart-5` · 사업형·행사 `--chart-2` · 기타 `--chart-3` |
| 채널(누구 것인가) | 줄 머리 글자 + 4px 브랜드색 띠(`channels.theme_color`, `ring-1 ring-black/10`) — 막대에는 쓰지 않음 | |
| 확정 정도(테두리) | 확정 = 1px 실선 / 예정 = 1.5px 점선 / 가안·가제 = 점선 + 제목 뒤 `(가제)` | |
| 날짜 정밀도 | 정확일·주 단위 = 막대 / 월 단위 = **범위 괄호**(├─┤, 2px 선) + `월 단위` 칩 + 원문(`1~2월`) / 첫방일만 = 막대 + 추정 끝 1주 흐림 + 점선 끝선 + `≈` | |
| 편성 형태 | 연속 = 막대 / 월 1회 = 얇은 선 + 방송일 ● / 단발·이틀 행사 = ◆(14px 미만이면 ◆ + `×2`) | |
| 작품 정보 없음(회색 전용) | 미정 = 흰 바탕 + 점선 `미정 · 12회` / 수급 = `--surface-muted` + 실선 `OTT 수급` / 휴방·결방 = 빗금 + 사유 | |
| 계산된 빈 주 | 상자 없이 1px 점선 밑줄 + `비어 있음 N주`(드라마 자리만) | |
| 바뀜 | 막대 오른쪽 위 8px 접힌 모서리(최근 14일 안 변경) | |

- 맞대결 초점(경쟁 비교에서 막대 선택): 겹치지 않는 막대는 **채움·테두리만** 흐리게(글자 대비 유지).
- 범례 2단: 기본 7개(드라마·예능·사업형·확정/예정·월 단위·미정·휴방) + `더 보기`.

## 5. 막대 글자

- 막대 안 최대 2줄: 1줄 제목(풀네임) / 2줄 `11/16~12/22 · 12회 · 주연1, 주연2`(넉넉 밀도만).
- 폭이 모자라면: 제목 풀네임을 막대 오른쪽 바깥(다음 막대 전까지 빈자리가 있을 때, 흰 받침) → `short_title`(DB, 사람이 정함) → 앞 글자 + `…` → 표식만. 제목은 아래 줄로 내리지 않는다.
- 화면 왼쪽 밖에서 시작한 막대는 제목이 보이는 영역 왼쪽에 따라붙는다.
- 인쇄: 제목이 안 들어간 막대는 번호를 달고 묶음 끝 각주로 풀네임.

## 6. 상세 패널(400px, 1536px 미만은 위에 겹침)

제목 풀네임·가제 여부 · 채널/방송사·자리 · 기간(실제 날짜 + 정밀도 원문) · 회차 · 상태 · 주연 · 연출/작가/제작사 · 로그라인 ·
OTT 표기 · **같은 시기 맞대결**(같은 요일·±60분·기간 겹침 목록) · 출처(자료 이름·기준일·셀 원문) · 변경 이력 3건.
관리자만: `고치기`(같은 패널 안 폼), `보관`(되살리기 가능).

## 7. 업로드

공통: 파일 선택 → **미리보기**(새로 생김 / 바뀜 / 그대로 / 확인 필요 / 사라짐 후보) → **반영** → 업로드 단위 **되돌리기**. 원본 파일은 저장하지 않는다(파일 이름·해시·셀 원문만).

**자사 라인업 양식**: 1행 제목(기간 원문), 2·3행 머리(장르·요일·시간대 / 월 / 주 월요일 날짜), 4행 `기념일·행사`, 그 아래 자리 행. 셀 `제목 M/D~M/D, N`(누적 회차·`월1회·마지막주` 같은 꼬리 포함), 바로 아래 행에 주연. 장르는 병합된 장르 열, 자리 = 요일 + 시간대. 연도는 머리 월 행(`1월 '27`)과 파일 제목으로 정한다. 단발(`11/14`)·이틀(`11/7~11/8, 2`)은 single/multi_day, `월1회`는 monthly. 사업형 판정: 셀 색 대신 관리자가 미리보기에서 고른다(기본: 이틀 이하 행사 = 사업형).

**업계 드라마 라인업 종합본**: 시트 `2026드라마-2nd`, `2027드라마`만. 시트마다 섹션(구분 = 월화 / 수목 / 주말(금) / 주말(토) / 주말(일)), 섹션 머리 2줄(월 / 주 날짜), 행 머리 = `방송사 [요일] 시각`. **병합 셀 = 구간**: 시작 = 첫 주 칸 날짜(섹션 첫 요일), 끝 = 마지막 주 칸의 그 주 블록 마지막 요일(정밀도 week). 셀 글자 `제목(회차) [제작사] 연출/작가/ 주연,주연`. 특수 셀 `휴방`→hiatus, `OTT 수급`→filler, `미정(N)`→tbd, 그 밖 작품 아닌 글자(`추석 아시안게임`)→hiatus + 사유. 같은 방송사·같은 제목이 토·일 섹션에 함께 있으면 **한 구간(요일 토일)**으로 합친다. 병합 안 된 한 칸 글자 = `확인 필요`. 방송사 표기 정규화(TVN/tvn → tvN, KBS → KBS2 등 `lineup_outlets.aliases`). ENA 줄은 D8 규칙.

## 8. 데이터 모델(마이그레이션 `20261124010000_lineup.sql`, 적용 전 사용자 승인)

UX 초안 9개 표를 7개로 줄였다(별칭은 작품 열 `aliases`, 셀 원문은 구간 열 `source_cell`·`source_text`, 행 단위 대외비 등급은 뺌 — 라인업 전체가 대외비).

| 표 | 내용 |
|---|---|
| `lineup_outlets` | 방송사·채널. 자사는 `channel_id`(channels) 연결. `code`·`display_name`·`side(own/rival)`·`aliases`·`sort_order` |
| `lineup_slots` | 자리. `outlet_id`·`name`·`days smallint[]`·`start_minute`(방송일 기준 분)·`time_note`·`compare_block(mon_tue/wed_thu/weekend/other)`·`default_genre` |
| `lineup_works` | 작품. `title`·`title_key`·`aliases`·`short_title`·`title_tentative`·`genre`·`total_episodes`·`cast_main`·`directors`·`writers`·`producers`·`logline`·`ott_note`·`program_id` |
| `lineup_runs` | 막대 하나. `slot_id`·`work_id`·`run_kind`·`status`·`start_date/precision`·`end_date/precision`·`start_text/end_text`·`episodes`·`episode_from/to`·`recurrence`·`air_dates`·`label`·`reason`·`source_id`·`source_cell`·`source_text`·`needs_review`·`archived_at` |
| `lineup_sources` | 업로드·입력 한 번. `source_kind`·`title`·`as_of`·`file_name`·`file_hash`·`change_note`·`summary`·`status(applied/rolled_back)`·`applied_by` |
| `lineup_events` | 공휴일 아닌 행사(대회·시상식·선거·기념일) |
| `lineup_changes` | 변경 이력(트리거가 `updated_by`로 씀) |

모든 표 RLS 켜고 정책 없음(서버 service_role만). 시드는 방송사 기준표만(작품 제목 없음).

그리드는 처음부터 `<table>` 하나: `thead`는 화면 `sticky top-0`·인쇄 반복, 첫 열 `th`는 `sticky left-0`, 막대는 각 행 `td` 안 절대 위치 `<button>`. 바깥 상자는 `overflow-auto dense-grid`(전역 `.overflow-x-auto` 표 축소 규칙을 피함).

## 10. 확장(7개 자사 채널·타사 예능)

- 자사 채널이 라인업을 가지면 같은 표에 행이 늘 뿐이다: 채널 묶음 A(ENA·ENA Drama·ENA Play) / B(OLIFE·ONCE·ENA Story·skyUHD) 머리로 접고 펼친다. 채널 선택 기본은 "라인업이 있는 채널 전부".
- 채널마다 자리 이름·요일·시각만 다르고 표·문법·업로드는 같다. ENA Play처럼 예능 위주 채널은 장르 거르기로 본다.
- 타사 예능 자료가 생기면 `default_genre = variety` 자리를 만들어 경쟁 비교에 장르 거르기로 함께 연다.
- 경쟁 비교의 자사 고정 줄은 "선택한 자사 채널"의 같은 묶음 자리로 바뀐다(ENA Drama를 고르면 ENA Drama 자리가 묶음 맨 위).
