# 라인업 월 단위 캘린더 보기 — 설계(구현 전)

작성 2026-11-25. 사용자 요청: "월 단위(날짜 지정 가능하게 해서) 캘린더 형태로도 보고 뽑을 수 있게".
지금 라인업 화면(`/lineup`, 간트형 격자)의 네 번째 보기로 붙인다. 데이터·권한·대외비 처리는 [통합 설계](LINEUP_DESIGN.md) 그대로이고 **DB 변경은 없다**(1단계).

---

## 1. 이 보기로 답하는 질문

| 우선 | 질문 | 지금 격자에서 어려운 점 |
|---|---|---|
| 1 | 이번 달(또는 고른 기간) **며칠에 무엇이 첫 방송·종영**하나? | 막대 끝을 눈으로 따라가야 한다 |
| 2 | **특정 날짜**(예: 성탄절·설 연휴 주간) 각 방송사가 그 시간에 무엇을 하나? | 하루 폭이 5px이라 날짜를 짚기 어렵다 |
| 3 | 우리 첫 방송 **그 주에** 타사는 첫 방송·종영·결방이 있나? | 묶음이 갈라져 한눈에 안 보인다 |
| 4 | 월간 회의·보고에 붙일 **한 달 달력 한 장**(인쇄·PDF·엑셀) | 격자 출력은 한 달만 보기엔 너무 넓다 |

## 2. 화면 구성

```
[자사 라인업 | 경쟁 비교 | 목록 | 캘린더]   [◀ 2027년 1월 ▶] [오늘]  기간 지정 [2027-01-15]~[2027-02-14]
채널[ENA ▾] 장르[…] 범위[자사만 · 자사+타사]  표시[주요 일정만 · 방송 모두]            [저장·인쇄]
┌────월────┬────화────┬────수────┬────목────┬────금────┬────토────┬────일────┐
│ 4        │ 5        │ …                                  ● 신정(1일)…        │
│ ▶ 첫방 ENA 가상극 1회 22:00                                                  │
│ ■ 종영 tvN 가상극B 12회                                                       │
│ ≈ 이 주 첫방 예정(주 단위): SBS 가상극C                         ← 주 단위 띠 │
├──────────┼──────────┼ …                                                     │
```

- **주 시작 = 월요일**(편성 주와 같게, 격자 보기의 주 머리와 맞춤). 한 달은 5~6줄(주).
- **날짜 지정**: 주소 `view=calendar&month=2027-01`(한 달) 또는 `view=calendar&dfrom=2027-01-15&dto=2027-02-14`(임의 기간, 최대 6주=42일). 임의 기간이면 그 기간이 든 주 줄만 그리고, 기간 밖 날은 옅게 비워 둔다. 화면의 '기간 지정'은 날짜 두 칸(시작·끝) + "한 달로 되돌리기".
- **표시 두 단계**
  - *주요 일정만*(기본): 첫 방송 ▶ · 종영 ■ · 단발·행사 ◆ · 휴방/결방 시작 ▨ · 월 1회 ● · 공휴일·대회. 칸이 작아도 읽힌다.
  - *방송 모두*: 그날 방송되는 모든 구간을 시각순으로(`22:00 ENA 가상극 5회`). 칸에는 3줄까지, 넘치면 `+4`를 누르면 그날 상세.
- **그날 상세(오른쪽 패널)**: 날짜를 누르면 "그날 편성 한눈에" — 시각 × 방송사 표(자사 고정 위). 막대 상세 패널과 같은 모양으로, 작품을 누르면 기존 상세 패널로 간다.
- 색·모양 문법은 격자와 같다(장르 = 채움색, 확정 실선/예정 점선, 회색 = 작품 정보 없음). 자사 줄은 채널 브랜드색 왼쪽 띠.

## 3. 날짜를 아는 정도를 정직하게 (격자와 같은 원칙)

| 자료 정밀도 | 캘린더에 놓는 법 |
|---|---|
| 하루 단위(자사 양식 등) | 그날 칸에 놓는다. 회차는 "첫 방송부터 그 자리 방송 요일을 센 순번"으로 **추정**해 `5회(추정)`처럼 쓴다(결방은 모르는 한 반영 못 함) |
| 주 단위(업계 종합본) | **특정 날에 놓지 않는다.** 그 주 줄 맨 위 얇은 띠에 `≈ 이 주 첫방: SBS 가상극C`로 쓴다(주 단위라는 사실을 숨기지 않음) |
| 월 단위(tvN 캡처 등) | 달 머리 아래 "이 달 예정(날짜 미정)" 상자에 모은다 |
| 첫 방송일만(MBC 캡처) | 첫방은 그날 칸, 종영은 회차로 추정한 날짜에 `≈ 종영(추정)` |

- 휴방·결방 구간과 겹치는 날은 그날 방송에서 뺀다(`hiatus` 구간 = 그 기간 그 자리 방송 없음).
- 단발·행사가 연속 편성 자리 위에 겹치면 그날 연속 편성은 `결방(행사명)`으로 적는다.

## 4. 저장·인쇄

지금의 '저장·인쇄' 창에 보기 `캘린더`를 더한다(같은 창, 같은 조건 항목 + 날짜 지정).

| 형식 | 모양 |
|---|---|
| 인쇄·PDF | 한 달 = 한 쪽(A4 가로 기본, A3 선택). 기간이 두 달에 걸치면 달마다 쪽을 나눈다. 머리 '대외비'·조건·출력 시각·자료 기준일(격자 인쇄와 같은 머리). 칸에 다 못 쓴 항목은 칸 안 `+N`과 쪽 아래 날짜별 각주 |
| 엑셀 | ① 달마다 시트 하나: 7열(월~일) × 주 블록, 날짜 칸 안 줄바꿈 목록(첫방·종영 굵게) ② '일별 목록' 시트: 날짜·요일·시각·구분(자사/타사)·방송사·제목·회차(추정 표시)·일정 종류(첫방/종영/방송/단발/결방)·정밀도 — 거르기·피벗용 |

## 5. 구현 메모(서버 계산 · 화면은 그리기만)

| 위치 | 하는 일 |
|---|---|
| `src/lib/lineup/calendar.ts` (새, 순수 함수) | `expandAirings(runs, slots, from, to)` — 구간을 날짜별 방송으로 펼친다(자리 요일·`air_dates`·월 1회 규칙·휴방 겹침 제거·회차 순번 추정). `calendarModel(payload, range, filters, mode)` — 날짜 칸별 항목(첫방/종영/방송/단발/결방), 주 단위 띠, 월 단위 상자 |
| `GET /api/lineup` | 그대로 쓴다(기간만 달력 범위로). 펼치기는 서버에서 하도록 `?shape=calendar`일 때 `calendar` 필드를 덧붙인다 |
| `src/app/lineup/CalendarView.tsx` | 7열 달력 그리기·그날 상세 패널 |
| `src/lib/lineup/excel.ts` | `buildCalendarSheets` 추가(달별 시트 + 일별 목록) |
| `src/app/lineup/print/PrintView.tsx` | `view=calendar`면 달마다 쪽 나눔(`break-after: page`) |
| `scripts/test-lineup.ts` | 펼치기 시험: 월화 12회 → 12개 날짜, 휴방 겹침 제거, 월 1회 마지막 화요일, 주 단위는 날짜에 놓지 않음, 회차 순번 |

- DB 변경 없음. 나중에 "특정 날 결방" 같은 날짜 단위 예외를 사람이 넣고 싶어지면 `lineup_run_exceptions(run_id, date, kind, note)` 하나만 더한다(2단계, 그때 승인).
- 주소는 기존 쿼리에 `view=calendar`, `month`, `dfrom`/`dto`(날짜)만 더한다. 격자 보기의 `from=YYYY-MM`과 겹치지 않게 캘린더 임의 기간은 `dfrom`/`dto`(YYYY-MM-DD)로 받는다.

## 6. 단계와 크기

1. 펼치기 순수 함수 + 시험(반나절)
2. 화면(달력·주요 일정/방송 모두·그날 상세)(1일)
3. 인쇄·PDF(달마다 쪽) + 엑셀(달별 시트·일별 목록)(반나절~1일)

## 7. 착수 전 사용자 확인

1. 기본 표시: **주요 일정만**(권장) / 방송 모두?
2. 기본 범위: **자사만**(권장, 타사는 켜면 보임) / 자사+타사?
3. 회차 추정(`5회(추정)`)을 보여 줄지 — 결방을 모르는 추정이라 빼자고 하면 첫방·종영만 쓴다.
4. 주 시작: **월요일**(편성 주와 같게, 권장) / 일요일(일반 달력)?
