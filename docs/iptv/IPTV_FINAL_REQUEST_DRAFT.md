# IPTV 마지막 묶음 요청 목록 초안 (12/23 무렵 전달용, 2026-11-15)

사용자 조건: 자료는 12월 말까지만 보장, 12/24쯤 끝날 수 있어 **12/23쯤 필요한 것을 한 번에** 말한다(2026-11-13). 아래는 지금까지 연구에서 "자료가 더 있으면 확정되는" 항목만 추린 초안이며, 전달 전에 사용자가 취사한다.

## 현재 적재 범위(2026-11-15 확인)
자사 6채널 + skyUHD 모두 가구·수도권 2049로 2024-07/08 ~ 2026-11-09/10까지 있다. 11/10 메모에 있던 "ENA 계열 11/1~ 공백"은 해소됐다.

## 1. 마지막 갱신(필수)
- 자사 6채널 + skyUHD + 경쟁 채널 전부: 11/10(또는 11/11) ~ 12월 마지막 일자(가구·수도권 2049). 이후 IPTV는 4단계 계획대로 계수 고정·화면 정리에 쓴다.
- 이유: 편성 변경 사후 효과(B1)·비교군 분포·구매 검토 IPTV 보조 블록이 모두 최근 구간까지 필요하고, 12월 이후에는 새로 쌓이지 않는다.
