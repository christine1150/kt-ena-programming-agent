# 방송 후 성과 회고 (단계 16)

방송이 끝난 주의 **확정 실적**을, 그 주 전날까지의 자료로 만들어 두었던 **당시 예측**과 견준다. `npm run retrospective`(읽기 전용)가 같은 표를 다시 만든다.

## 방법

- 자료: 저장된 백테스트 결과(`ideal_schedule_backtest_results` 59개, 채널 7개·6주). 예측은 각 주의 전날까지의 자료만 쓴 값이고(미래 자료 누출 없음, OPT02 테스트가 확인), 실적은 방송 후 확정된 닐슨 값이다.
- 비교 대상: **실제로 방송된 편성**의 방영별 예상과 실적. 같은 타깃끼리만 견주고, 2049와 가구 값은 합치지 않는다(전체 줄도 타깃별로 따로).
- 지표: MAE(%p, 예상과 실적 차이의 절대값 평균) · 편향(예상−실적 평균, 양수=예상이 높았음) · 상대 MAE(MAE÷실적 평균) · 범위 적중(실적이 예상 범위 안) · 근거 등급 A/B/C(같은 슬롯·같은 프로그램 근거가 충분한 정도).

### 읽는 법과 한계

- **편향은 작다**(예상−실적 평균이 ±0.013%p 이내). 예측이 한쪽으로 치우치지는 않았다.
- **상대 오차는 크다.** 2049는 시청률 수준이 0.0x%라서 MAE 0.034%p가 실적 평균의 약 72%이고, ENA PLAY·skyUHD는 100%를 넘는다. **방영 한 편의 값을 맞히는 용도로는 정확하지 않다.** 근거 등급별 절대 오차도 기대와 달랐다 — 수도권 2049의 MAE는 A등급(근거 충분) 0.038 · B 0.031 · C(근거 부족) 0.028%p, 가구는 A 0.037 · B 0.034 · C 0.026%p로 **근거가 많다고 절대 오차가 작지는 않았다.** 근거가 많은 슬롯이 시청률 수준이 높은 슬롯이라 절대 오차가 크게 나왔을 가능성이 있는데, 등급별 상대 오차는 계산하지 않아 이 설명을 확인하지 못했다(등급이 '더 믿을 만하다'는 표시의 근거는 이 자료로는 확인되지 않았다).
- 범위 적중률은 2049 86%·가구 77%로 명목 80% 근처이지만, 가구는 80%에 못 미치고(OLIFE 76%, ONCE 77%, ENA STORY 78%) 범위가 없는 방영(OLIFE 560건)이 빠져 있다.
- 이 표는 **예측 정확도**다. 이 예측이 만든 편성안을 방송해서 시청률이 올랐는지(실제 효과)는 이 표가 말하지 않는다.
- 저장 시점의 모델 버전은 백테스트 실행(2026-09-30)이 기준이다. 이후 모델(OPT02)이 바뀌었으면 같은 주를 다시 돌려야 현재 모델의 정확도를 알 수 있다.
- 합격선(OPT05 제안)은 승인 대기라 이 값에 PASS/FAIL 판정을 내리지 않는다.

## 인과를 주장하지 않는다

관측된 시청률 변화를 **AI 단독 인과 효과로 주장하지 않는다.** 방송하지 않은 대체안의 예상치는 실적이 없으므로 검증 성과로 쓰지 않고, 직전 주 같은 슬롯 실제값은 참고값일 뿐이다(공휴일·경쟁·프로모션 등 교란 요인이 같이 움직인다). 채택 기록(봉인 스냅샷)이 쌓이면 `settleAdoption`(OPT05)으로 같은 타깃·같은 분모에서 예상과 실적을 대조하고, 교란 후보를 결과에 붙여 보여 준다.
