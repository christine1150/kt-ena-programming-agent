## 지표 표기(`src/lib/ui/metricFormat.ts`)

| 지표 | 이름 | 단위 | 자릿수 | 비고 |
|---|---|---|---|---|
| rating | 시청률 | % | 3 | 순간 평균. skyUHD만 5자리 |
| share | 점유율 | % | 2 | 같은 시간 TV 시청 중 비중 |
| reach | 도달률 | % | 2 | 한 번이라도 본 사람의 비율 |
| timeSpentRatio | 시청시간 비율 | % | 2 | 공급자 정의 그대로(합산·평균 금지) |
| timeSpent | 1인당 시청시간 | 분·초 | 0 | 초 단위 값을 분·초로 표기 |
| rank | 순위 | 위 | 0 | 순위 종류·타깃·기간을 옆에 표기 |
| index | 지수 | — | 1 | 기준 100, 퍼센트가 아님 |
| airings | 방송 횟수 | 회 | 0 | 패널 표본 수가 아님 |

결측은 `—`, 0은 관측값 `0`, 극소값은 `<0.001`(skyUHD는 `<0.00001`), 음수는 수학 빼기 기호(−), 천 단위 쉼표, 숫자 열은 오른쪽 정렬+고정폭 숫자.
시간은 초를 먼저 정수로 반올림한 뒤 분·초로 나눠 `28분 60초`가 생기지 않는다.

## '평소'의 기준 — 화면마다 달랐다

같은 '평소'가 화면마다 다른 기간을 가리키고 있었다. 각 문구에 데이터 출처에서 확인한 기준을 적었다.

| 어디 | 기준 | 근거 |
|---|---|---|
| 홈 채널 서술(순위·강세 시간대·시청률 비교) | 최근 4주(28일) 평균 | `get_channel_daily_narrative`의 `narrative_28` |
| 채널 화면 프라임·시간대 기준선 | 최근 12주(84일) 평균 | `hourlyBaselinePattern`, `primeBaseline` |
| 채널 화면 헤드라인(시청률·점유율·순위) | 선택한 요일의 최근 N주 평균, 없으면 최근 12주 평균 | `baselineLabelText` |
| 인구통계(연령대) 비교 | 최근 한 달 평균 | `baselineWord` |
| 프로그램 슬롯 지수 | 같은 슬롯 평균 = 100 | 지표 계약 §6 |
| 보고서 슬롯 편차 | 같은 슬롯 기준선(‘기준선’ 열) | `programsBySlotDeviation` |
| 질의응답 기간 성과 | 최근 12주 평균 | `responseTemplates.ts`의 비교 기준 문구 |

> 기준이 서로 다르다는 사실 자체는 바뀌지 않았다. 4주·12주·한 달을 하나로 통일할지는 지표 정의의 문제라 사용자 결정이 필요하다(PROGRESS.md 단계 15 ‘결정 요청’).
