# OPT02 — 슬롯·회차별 기대 시청률 예측: 시간 순서 검증 결과와 결정

작성: 2026-10-07 · 도구: `src/lib/idealSchedule/validation.ts`(순수 하네스), `scripts/opt02-eval.ts`(`npm run opt02:eval`), 테스트 `npm run test:opt02`(34).
**실행한 범위만 보고한다.** 아래 표는 **합성 세계**(프로그램 34개·40주·세계 6개, 프로그램 신규 투입·종영·본/재방·특집·새벽 0시청률·주별 추세 포함)에서 낸 것이다. **실제 채널의 결과가 아니며** 실제 자료로 같은 표를 만드는 절차(§6)만 준비했다. 운영 DB는 읽지 않았다.

## 1. 결론

1. **현재 모델(6단계 수축 기대값)을 유지한다.** 같은 테스트 구간·같은 지표에서 단순 기준모델(같은 요일·시간대 최근 평균, 같은 프로그램 최근 평균, 두 기준의 부분풀링)보다 MAE가 낮았다(기본 설정 1.756%p vs 최선 기준 2.114%p, −17%).
2. **더 복잡한 모델을 승격하지 않는다.** 하이퍼파라미터(수축 강도 k·최근 가중)를 튜닝 구간에서 고른 변형은 최종 holdout에서 기본과 사실상 같았다(1.743±0.150 vs 1.756±0.142, 세계 간 편차 안). 새 특징(회차·시즌·노출 간격·계절)은 이 합성 세계에 그런 효과가 없어 검증할 수 없고, **데이터에 없는 반복피로 곡선을 정답으로 하드코딩하지 않았다.**
3. **백테스트 가정이 낙관적이다.** 현재 백테스트는 데이터 마감을 "목표 주 전날"로 가정한다. 실제 편성 작업은 보통 1~2주 전에 하므로 마감을 7·14일 앞당기면 MAE가 1.756 → 1.871(+6.5%) → 1.992(+13.4%)로 커진다. **검증 결과를 보고할 때 마감 간격을 함께 적어야 한다.**
4. **구간(80%)은 "과거 오차의 실증 범위"다.** 이전 목표 주 잔차의 10~90% 분위수로 만든 구간의 이후 적중률은 약 79%(명목 80%)였다. 단, 상대 폭이 약 105%(예측값만큼 넓음)이고 합성 세계의 오차 분포가 시간에 따라 변하지 않아 적중이 잘 맞은 것일 수 있다. **미래 80% 보장을 약속하지 않는다.**
5. **신규 프로그램·소표본은 개선되지 않았다**(MAE 약 4.6%p로 기준모델과 같음). 이 영역은 "근거 부족" 표시와 넓은 범위로 다루고 고확신 수치를 만들지 않는다(현재 방식 유지).

## 2. 예측 단위와 예측 시점에 알 수 있는 데이터(available_at)

예측 단위: **채널 × 최적화 타깃(KPI 또는 선택 타깃) × 방송일의 요일·시(hour 버킷) × 프로그램(program_id, 본·재·미표기 구분) 하나**. 에피소드·시즌은 별도 키가 없다(프로그램 id는 회차를 제거한 정규화 이름 단위라 시즌이 합쳐질 수 있음 — 한계). 반환값은 **산술평균 기대값**(비율합 지수 × 슬롯 baseline, 로그 변환 없음)이며 주간 기대값 집계(편성 분 가중 산술평균)와 같은 단위다. [코드 확인: `features.ts:219-260`, `engine.ts:489-523`]

| 입력 | 예측 시점 규칙 | 강제 여부 |
|---|---|---|
| 자사 방영·시청률 | `broadcast_date ≤ as_of`(RPC SQL + 엔진 `eligibleAirings` 이중 방어), 학습 창 91일, 공휴일 제외 | **강제됨** |
| 데이터 도착 지연 | 시청률 파일은 방송 다음 날 이후 도착. 엔진은 as_of=목표 주 전날을 가정 | **모델링 안 됨** → 검증 하네스에 `leadDays`(0/7/14)로 민감도 표시 |
| 경쟁 방영 | `≤ as_of` | 강제됨 |
| 과거 주 검증 잔차(예상 범위) | `week_start ≤ as_of − 6`, 같은 주 여러 번이면 최신 1개 | 강제됨(단 잔차 자체가 검증 당시 *현재 값 설정*으로 만들어짐) |
| 장르 맵 | 현재 값으로 과거 방영 장르 분류 | **버전 없음** → 이번 단계에서 장르 분류 지문을 실행 지문·요약에 기록 |
| 채널 설정·가중치 | 현재 값 | 버전 없음 → 설정 지문 기록 |
| 필수 편성·잠금 제약 | 현재 값 | 버전 없음 → 제약 지문 기록 |
| 업로드 편성표 회차·부제 | 대상 주 계획은 방송 전 확정이라 허용. 방송 후 수정·재업로드는 시점 관리 없음 | 버전 없음(검증 시 누수 가능) |
| 권리(Avail) | 현재 값 | 버전 없음 |

`UNVERSIONED_INPUTS`(validation.ts)가 위 목록을 코드에 두어, 검증 출력마다 "현재 값으로 과거를 재현한 입력"을 밝힌다. 실제 `available_at` 컬럼을 장르 맵·설정·제약에 추가하는 것은 DB 마이그레이션이 필요해 이번에는 하지 않았다(지문 기록으로 *재현 가능 여부를 감지*하는 데까지).

## 3. 비교한 모델(같은 테스트 구간)

| 모델 | 정의 |
|---|---|
| ★ 현재 모델(기본 k=4, 최근가중 2) | 6단계 수축 기대값(§OPT_PIPELINE 3절) |
| 현재 모델 변형 9종 | k∈{2,4,8} × 최근 가중∈{1,2,4} — 튜닝 구간에서 선택 |
| 채널 최근 4주 평균 | 슬롯·프로그램 무시(최저 기준선) |
| 같은 요일·시간대 최근 4/8주 평균 | 없으면 같은 시 평균 → 채널 평균 |
| 같은 프로그램 최근 4회 평균 | 슬롯 무시, 없으면 슬롯 기준 |
| 프로그램·슬롯 부분풀링(k=3) | α·프로그램 평균 + (1−α)·슬롯 평균, α = n/(n+k)(이력 없으면 슬롯 평균으로 수축) |

검증 방식: 목표 주마다 as_of = 목표 주 시작 −1 − 마감 간격으로 학습 자료를 자르고 그 주의 모든 방영을 예측(시청률 NULL·공휴일 방영 제외). 목표 주 24개/세계, **앞쪽 절반으로 변형을 고르고 뒤쪽 절반(최종 holdout)에서 한 번만 보고**. 무작위 분할 없음.

### 4-3. 튜닝/최종 holdout 분리

튜닝(앞쪽 절반)이 고른 변형 분포: k=8·rw=4 3회, k=2·rw=4 2회, k=4·rw=4 1회(세계 6개). 최근 가중 4가 매번 뽑혔다. holdout MAE: 튜닝 선택 **1.743±0.150** / 기본 **1.756±0.142** / 기준모델 중 튜닝 최선 **2.117±0.197**. 선택 효과(−0.013)는 세계 간 편차보다 훨씬 작다 → **승격 근거 없음**. 다만 "최근 가중 ↑"의 방향이 모든 k에서 일관(단조 개선)하므로 OPT05의 실제 자료 최종 검증에 후보(rw=4, k=8)로 포함할 가치는 있다.

채널·타깃(KPI)별로 반복한다. 출력에는 현재 모델·변형·기준모델의 MAE/bias/RMSE/구간 적중률/폭, 집단별 표(신규·이동·소표본·저시청·프라임·본/재방), 마감 간격 0/7/14일, 표본 노출이 포함된다. 장르는 실제 장르 맵을 쓰지 않고 "미분류"로 두므로(장르 단계 폴백 제외) 장르별 표는 아직 없다.

## 7. A/B 등급 규칙(문서화)

화면의 근거 등급은 `fallbackLevel`로 정한다(`model.ts evidenceGrade`): **A** = 프로그램×방영유형의 같은 요일·시 또는 같은 시 이력이 `minN`(기본 3) 이상(1~2단계) + 신뢰도 ≥ 0.005, **B** = 프로그램 전체 이력(3단계)이거나 표본이 적어 신뢰도≈0, **C** = 프로그램 자체 이력 없이 장르·채널 평균(4~6단계), **가정** = 경쟁 프로그램 지수 전이. 예상 범위는 등급별 과거 오차 분포를 쓰고(등급 표본 30건 미만이면 전체를 합쳐 사용), 등급은 신뢰도·표본의 조합이지 통계적 유의성 판정이 아니다.

## 8. 남은 한계

- 합성 세계 결과다. 실제 채널의 비정상성(특집·휴일·경쟁 편성·프로모)이 있으면 순위와 크기가 달라질 수 있다 → §6 절차로 실제 자료 재현 필요(OPT05의 입력).
- 장르 단계(④⑤)는 합성 장르가 실제 시청 성향과 무관해 효과를 검증하지 못했다.
- 마감 간격 민감도는 `leadDays`로 표현했지만 실제 시청률 파일 도착 지연(D+1~2)은 별도로 모델링하지 않았다.
- 구간 적중률은 같은 세계에서 오차 분포가 안정적이라 낙관적일 수 있다.
