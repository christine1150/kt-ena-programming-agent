# 닐슨 메일 자동 수집 설정(기술 문서)

관리자 화면에는 연결 상태·마지막 성공·오류만 표시한다. 자격증명은 화면이나 채팅에 입력하지 않고 `.env`(로컬)와 배포 환경 변수(Vercel)에만 둔다.

## 네이버 메일(IMAP) — 현재 사용 경로
1. 네이버 메일 → 환경설정 → POP3/IMAP 설정에서 "IMAP 사용"을 켠다.
2. 2단계 인증을 쓰면 네이버 계정 → 보안설정 → 2단계 인증에서 이 서비스 전용 앱 비밀번호를 발급한다(쓰지 않으면 평소 비밀번호).
3. `NAVER_MAIL_USER`(메일 주소)와 `NAVER_MAIL_PASSWORD`(위 비밀번호)를 `.env`와 배포 환경 변수에 추가한다. 값은 저장소에 커밋하지 않는다.

## Gmail(선택)
그룹웨어 2FA 때문에 Bizbox 메일을 직접 자동화하기 어려울 때 Gmail로 전달받아 쓰는 대체 경로다. `GMAIL_USER_EMAIL`, `GMAIL_CLIENT_ID`, `GMAIL_CLIENT_SECRET`, `GMAIL_REFRESH_TOKEN`을 채우면 활성화된다.

## 동작 확인
- 관리자 화면 "수신·반영 현황"의 메일 수집 줄에서 마지막 성공·마지막 오류 시각을 본다.
- 오류 메일은 30분 간격으로 최대 3회 재시도하고, 그 뒤에는 자동 재시도를 멈춘다(관리자 확인 대상).
