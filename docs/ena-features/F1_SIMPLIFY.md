## 1. 현재 지표 정의 점검(코드 확인)

## 2. 바뀐 화면

- 첫 화면: 핵심 한 줄(KPI 그룹별) → 수도권 2049 표 / 전국 유료가구 표(채널·작품 평균·채널 평균·대비·관측 방송일) → 월간 성과 추이.
- 핵심 한 줄은 서버 템플릿(`headlineFor`) — 상회/하회 방향과 표본 상태만 쓴다. LLM·권고 문구 없음.
- 월간 추이(`monthlySeries`): 선택한 채널의 월별 작품 평균과 **같은 달·같은 날짜 구간**의 채널 평균. 조회 기간에 잘린 달은 날짜 범위를 표시, 방영 없는 달은 '방영 없음'(0으로 잇지 않음).
- 접힌 영역: 본방·재방 성과 / 동슬롯 비교·현재 판정(판단 근거·요일×시간대별 평균) / 근거 방송 목록. 개별 방송 막대 목록(회차·방송일 추이 탭)은 근거 방송 표와 같은 내용이라 뺐다.
- 검색: 검색·분류 버튼을 누르면 선택된 작품을 풀고 후보만 보여 준다(이전 상세와 섞이지 않음). 아무것도 없이 들어오면 주요 오리지널 작품 목록(최근 방영 순). 필터는 한 줄(기간·채널 펼침·타깃·본재).
- 응답 버전 `program-performance-v1.1`(계산식 동일, 응답 필드 추가 — 캐시 섞임 방지).

## 2-1. 화면·문구 2차 수정(2026-10-22, `KT_ENA_프로그램성과_화면문구_수정지시문.md`)

- 삭제: 부제, 회색 요약 상자(핵심 한 줄 — 서버 `headlines` 필드는 남아 있으나 화면에서 쓰지 않음), 표 아래 면책 문단, 월별 추이의 막대·같은 유형 평균 설명, '두 기준 함께 보기' 열, 표 제목의 'KPI 채널' 꼬리, 제목 옆 기간·타깃 반복.
- 비교표 4열(채널·작품 시청률(%)·채널 평균(%)·채널 평균 대비). 대비는 부호+색만(`+65%`), 뜻은 접근성 텍스트. 표본 적은 채널은 채널명 옆 작은 `(3일)`(주황=8일 미만 자료 적음, 빨강=3일 미만 자료 부족, 마우스 올림·접근성 텍스트에 '자료 적음 · 3일', 계산 기준에 설명 — 사용자 요청으로 아랫줄 대신 한 줄).
- 비교 제외 채널(skyUHD 등)은 표에서 빼고 '비교 제외 n개 채널' 펼침으로. 비교 가능 채널이 하나도 없으면 이유를 바로 표시.
- 기간은 필터 영역에 한 번(실제 집계 시작~종료일). 채널·타깃은 '비교 설정' 펼침. 방송 구분 '전체 방송/본방/본방 외' + 선택 시 짧은 도움말.
- 월별 추이: 월(열) × 작품 시청률·채널 평균·채널 평균 대비(행) 숫자 표. 일부 기간 달은 제목에 날짜(`9월 24~30일`). 좁은 화면은 월을 행으로. 방영 없음·자료 없음·0 구분.
- 채널 상세(표의 채널명 또는 채널 버튼으로 하나만 엶): 방송 구분별 성과(본방·확인된 재방·본방 여부 미확인 중 실제 있는 것), 같은 시간대 대비(%, 배율, 비교 기간, 작품 방영/비교 방송 수), 집계 기준(집계 방송일·방영 횟수·회차·작품 방영 기간·채널 평균 자료 일수·배율), 방송 기록(원본 태그는 여기서만), 그 안에 요일·시간대별 평균.
- 최근 12주 편성 진단은 채널 상세 아래 독립 상자 — 콘텐츠 적합도 결과의 자체 평가 기간·표본만 표시(조회 기간 표본 경고와 섞지 않음). 비교표에는 판정 태그를 붙이지 않는다.
- '계산 기준' 펼침(키보드·터치 가능): 작품 시청률·채널 평균·상대 차이(%p 아님)·본방 구분·자료 적음 기준·같은 시간대 대비.
- 계산식·서버 응답 무변경(이 단계는 화면 파일만).

## 2-2. 사용자 추가 요청(2026-10-22)

- 방영 기록이 있는 채널만 표·월별 추이·채널 상세에 표시(관측 없음·자료 없음 채널 행 제거, 비교 제외는 기존대로 표 아래).
- 첫 줄(채널마다, 서버 고정 템플릿 `channelLine`): "{기간} 기간 동안 {채널}({KPI 타깃})에서 평균 시청률 {값}({n}회)로 채널 평균 대비 {±%}. 채널 평균보다 높아 채널 시청률에 도움이 되고 있습니다 / 낮아 … 도움이 되지 못하고 있습니다 / 비슷한 수준입니다." 방송일 3일 미만은 판단 보류, 8일 미만은 '(자료 적음 · n일)'. 이전 그룹 요약(`headlines`)은 제거. 지시문(간결화)의 '도움' 같은 인과 표현 자제와 다르지만 사용자가 직접 요청한 문구 — 뜻은 '채널 평균보다 높은지'의 서술.
- 채널마다 수도권 2049·전국 유료가구 두 행(새 타깃 모드 `both`, 기본값). 채널 KPI 타깃에 'KPI' 표시·먼저. 총계·근거 방송·첫 줄·12주 판정은 KPI 타깃 기준(같은 방영 두 번 세지 않음). 응답 버전 v1.2, 계산식 무변경.
- 채널 평균보다 좋으면 푸른색(`text-blue-700`), 나쁘면 붉은색 — 부호와 함께.

## 2-3. 분석 구조 재배치(2026-10-22, `분석 구조·화면 수정 지시문` — 사용자 지시로 의미 있는 항목만 반영)

- 구조: 채널별 성과 비교표 → 행(채널·타깃) 선택 → 2×2 분석(시청률 흐름·최고/최저·편성 비교·종합 평가) → 상세 한 곳(방송 구분별 성과·방송 기록). 기존 월별 표·채널 상세·요일×시 목록·최근 12주 진단 상자는 이 구조로 통합·대체.
- 비교표 열: 채널·타깃·시청률(아래 작은 '채널 평균')·점유율·채널 평균 대비·같은 시간대 대비. 대비 두 열은 '시청률 기준 상대 차이(%)'라고 표 아래 명시. 좁은 화면은 타깃을 '2049/가구'로 줄여 375px 안에 들어감.
- **점유율 확인**: `ratings.share`는 닐슨 일일 파일 타깃상세(및 ONCE·OLIFE·ENA STORY 자사 블록) 시트의 '점유율' 열(시청률 다음 칸)이며 `time_spent_share`(시청시간 비율)와 다른 열(`nielsenDaily.ts`). 프로그램 행 채움 확인(2026-09-01~10-20, 전 채널 rows=share 건수). 화면 값 = 선택 조건 방영별 점유율의 산술평균(`shareStat`, NULL 방영 제외·0은 유효) — 채널 기간 공식 점유율로 쓰지 않는다고 계산 기준에 명시.
- 시청률 흐름(`trendTextOf`): 회차별 = `<본>` 표시+회차 번호 방영만(재방을 다음 회차로 잇지 않음). 4회차 이상 전반/후반 평균, 2~3회차 첫/최근, 그 외 방영이 있는 첫·마지막 달의 채널 평균 대비. 근거 하나면 '추이 자료 부족'. 그래프는 이 영역 안에서만(회차/월 전환). 현재 운영 자료는 회차 번호가 거의 비어 대부분 월별로 표시됨.
- 최고·최저(`extremesOf`): 선택 기간·방송 구분 안 개별 방영의 최고·최저·최근('최종회' 대신 '최근 방영' — 완결 여부 미확인).
- 편성 비교(`slotLinesOf`): 실제 방영한 요일×시마다 작품 평균 vs 같은 채널·타깃·비교 창의 같은 요일·시 다른 프로그램 **단순 평균**(표의 수축 배율과 다른 지표라고 명시). 비교 방송 15건 미만이면 같은 시(전 요일)로 넓히고 '전 요일' 표시, 그래도 부족하면 산출 안 함. 방송일 3일 미만 구간은 판단에 쓰지 않고, 대표 구간은 극단값이 아니라 방영이 많은 구간. 미방영 시간대는 만들지 않음.
- 종합 평가(`verdictOf`): 채널 평균 대비 × 같은 시간대 대비 방향의 고정 문구 + 근거 최대 2개(시간대별 엇갈림, 전체는 높지만 본방 외는 낮음, 자료 적음). 태그·점수·권고 없음. 최근 12주 진단은 채널 화면(`/channel/{code}#content-fits`) 링크로만.
- 반영하지 않은 것: 같은 유형 평균·순위(§3 이유 그대로), 표본 표시 문구 변경(사용자가 앞서 요청한 채널명 옆 `(n일)` 유지), 첫 줄 문장(사용자 요청 유지).
- 응답 버전 v1.3(기존 값 계산식 무변경, 필드 추가).

## 2-4. 사용자 추가 요청(2026-10-22, 걸어서세계속으로 화면)

- 첫 줄을 채널당 한 줄로: "{기간} 기간 동안 OLIFE에서 평균 시청률 가구 0.200·2049 0.004(168회)로 채널 평균 대비 가구 +73%·2049 +29%. 두 타깃 모두 …" (`channelLineOf`). KPI 타깃 먼저, 판단은 KPI 타깃 기준, 두 타깃 방향이 다르면 '다만 …'으로 덧붙임. 타깃이 하나인 모드는 기존 문장 그대로.
- 경쟁 채널 성과(선택해서 열기): `competitor_program_target_ratings`(닐슨 경쟁채널 시트, 등록 경쟁채널만)에서 작품 정규화 키가 같은 방영. 시트 타깃 '개인2049'→수도권 2049, '유료방송가구'→전국 유료가구. 채널 평균은 `competitor_ratings`의 순위 있는 하루 행 일평균(자사와 같은 정의). <본>/<재> 태그로 방송 구분, 자사와 같은 이름의 경쟁채널 항목 제외, 같은 방영 한 번만. 같은 시간대 비교는 경쟁 채널 편성 전체가 없어 내지 않음.
- 확인: 걸어서세계속으로 최근 12주 — KBS JOY 33회, KBS1 24회. '걸어서세계속으로 트래블홀릭'(KBS1·KBS2·KBS Story)은 다른 프로그램이라 합치지 않음(자사와 같은 이름 규칙 — 합치려면 관리자 별칭 승인).
- 응답 v1.4, 테스트 99건.

## 3. 하지 않은 것과 이유

- **같은 유형 평균(자체드라마 본·재, 자체예능 본·재)**: 사내 월간 추이 표(`channel_monthly_genre_trend`, ENA 2026년 1~8월, 스크린샷 전사본)와 앱 자료를 대조했다. 주요 콘텐츠 목록(`featured_content`) 분류 + `<본>` 표시로 월별 산술평균을 내면 자체드라마(본)은 8개월 중 5개월이 일치하지만 4·8월이 다르고, 자체예능은 대부분 다르다(예: 1월 예능(본) 0.596 vs 0.472). 사내 표의 작품 분류·집계 규칙이 앱 자료로 재현되지 않으므로 표시하지 않고 화면에 '아직 표시하지 않음'으로 적었다. 또한 `<본>` 표시가 ENA에만 있어 다른 채널의 본·재 유형 평균은 원천적으로 만들 수 없다.
- 본재 전환 시 채널 평균은 바꾸지 않는다(채널 전일 기준 — 지시문 v2 §5-4). 본재가 반영된 대응 비교군은 위 같은 유형 평균이 검증된 뒤에만 가능.
- 운영 배포·푸시(A4)는 사용자 화면 확인·승인 전 하지 않음. A1/A2(예측 저장)와 섞지 않음.
