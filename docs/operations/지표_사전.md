# 지표 사전

화면·보고서·문서가 같은 말을 쓰도록 정한 이름과 표기다(코드: `src/lib/ui/glossary.ts`, `metricFormat.ts`). 공급자 파일의 컬럼 이름이 다른 것은 아래 '원본 용어'에 따로 적었다.

| 지표 | 뜻 | 단위·표기 | 주의 |
|---|---|---|---|
| 시청률 | 그 시간 평균 시청 비율(순간 평균) | % 그대로(×100 하지 않는다). 일반 채널 소수 3자리, skyUHD 5자리 | 0.11358은 0.11358%다. 11.358%가 아니다. 0과 '자릿수에서 0'(`<0.001`)을 구분한다 |
| 점유율 | 같은 시간 TV 시청 중 비중 | % 소수 2자리 | 여러 날 값으로 합치거나 평균내지 않는다 |
| 도달률 | 한 번이라도 본 사람의 비율 | % 소수 2자리 | 일간 값을 합산·평균해 주간 도달률을 만들지 않는다(공급자 정의) |
| 시청시간 비율 | 공급자가 주는 시청시간 비율 | % 소수 2자리 | 단순 합산·평균 금지 |
| 1인당 시청시간 | 초 단위 값을 분·초로 표기 | `28분`·`28분 5초`(60초가 되면 올림) | 초를 먼저 정수로 반올림한 뒤 나눈다 |
| 공식 순위 | 공급자 원본의 순위(No.) | 정수 + '위' | 일간·주간 파일의 값. 행 번호로 다시 만들지 않는다 |
| 일별 순위 평균 | 일별 순위의 평균 | '일별 순위 평균 41위'처럼 이름을 붙인다 | 공식 기간 순위와 다르다. 정수여도 이름으로 구분 |
| 지수 | 기준 대비 상대값(기준=100) | 소수 1자리, `%` 없음 | '153.8 지수'는 시청률 153.8%가 아니다 |
| 변화 | 값 차이 `+0.030%p`, 상대 변화 `+12.3%` | 둘을 따로 | 기준값이 0이거나 극소면 '신규(기준 0)'·'산출 불가' |
| 방송 횟수 | 편성(방영) 건수 | N회 | 패널 표본 수가 아니다. 같은 회차 재방은 독립 표본이 아니다 |

## 원본 용어

공급자(닐슨) 파일에서 쓰는 이름을 그대로 읽는 곳(파서)에만 남아 있고, 화면·보고서는 위 표의 이름을 쓴다.

원본 용어: 도달율(닐슨 시트의 컬럼 이름) = 화면 이름 '도달률', Reach(영문 표기) = '도달률'
원본 용어: 시청시간비율(닐슨 시트의 컬럼 이름) = 화면 이름 '시청시간 비율'

## 기간 말

- **일간**: 방송일 하루. 방송일은 02:00~다음 날 02:00이고 24시 이상은 방송일을 유지한다(10/4 25:30은 달력상 10/5 01:30).
- **주간**: 월~일 7일 완결주. **월간**: 달력월. **월누계**: 전월 같은 일수와 비교한다.
- **잠정**: 일간 값으로 만든 임시 기간 값(수신 일수 표시). **공식(확정)**: 공급자 기간 파일의 값.
- 비교 기준 말: '최근 4주 평균'(홈 서술), '최근 12주 평균'(채널 화면 프라임·시간대), '최근 한 달 평균'(연령대), '같은 슬롯 평균=100'(슬롯 지수). 화면마다 쓰는 기준이 다르다 — 문구에 기준이 적혀 있다.

## 타깃

- 그룹 A(ENA·ENA Drama·ENA Play): 수도권 개인 2049. 그룹 B(OLIFE·ONCE·ENA Story·skyUHD): 전국 유료방송가입가구.
- **서로 다른 타깃(2049와 가구)·지역(수도권과 전국)·그룹의 값은 합치거나 한 열에서 비교하지 않는다.** 순위도 타깃이 다르면 다른 순위다(ENA 주간: 2049 7위, 전국 가구 12위).
