# 운영자 사용 가이드

## 매일 하는 일

1. **관리자 › 자료 수신·반영 현황**을 먼저 본다. 채널×자료 종류별로 '정상·미수신·실패·미반영·재계산 대기'가 나온다. 이상이 없으면 아래는 건너뛴다.
2. 닐슨 파일이 메일 자동 수집으로 들어오지 않았으면 **Nielsen 시청률 업로드**에 직접 올린다. 일간·주간·월간은 파일 안의 분석기간으로 자동 구분된다. 같은 파일을 다시 올리면 '변경 없음'으로 건너뛰고, 같은 기간의 수정본이면 차이를 보여 주며 새 개정으로 반영한다.
3. skyUHD(수기 누적 파일)와 OLIFE EPG는 해당 업로드 카드에 올린다. EPG는 닐슨과 시작시간 ±60분으로 맞추고, 못 맞춘 방송은 '미매칭' 목록에 남는다.
4. 올린 뒤 수신 현황에서 해당 날짜가 '반영'으로 바뀌었는지, '재계산 대기'가 풀렸는지 본다.

주 1회·월 1회: 주간·월간 파일 올리기, 목표 시청률·Channel Master 변경이 있으면 반영(수동 입력한 목표는 잠겨서 파일 재업로드가 덮지 않는다), Avail 변경이 있으면 Avail 관리에서 반영.

## 화면을 읽는 순서 (PD)

1. **브리핑(홈)**: 맨 위 '데이터 상태'(수신 지연·잠정 여부) → '오늘의 결정' 카드(최대 3건) → 근거·대안 링크.
2. 카드의 **제목이 '추적 점검'이면** 1회 하락이라 교체·이동을 권하지 않는다는 뜻이다. '교체 검토'·'이동 검토'는 같은 하락이 반복 관측됐을 때만 나온다.
3. 근거를 보려면 카드의 링크로 **채널 분석**(같은 채널·기간으로 열린다)에 간다. 기간·채널을 바꾸면 이전 값은 '이전 선택의 값'이라고 표시되고 새 값이 오면 교체된다.
4. 편성안은 **AI 편성(시청률 자판기)**: 조건을 정하고 '편성표 뽑기'. 결과는 '기준안·최소 변경·균형·성과 우선' 카드로 비교한다. 수동으로 바꾼 칸은 '수동 변경'으로 잠기고 합계는 재평가 뒤에 갱신된다.
5. **확정 준비 검사**는 읽기 전용이다. 권리 미확인·필수 편성 위반·화면이 본 버전과 다른 수정이 있으면 '검토안만'으로 남고 '실행 가능'으로 표시되지 않는다.

## 저장·검토·확정·내보내기

| 말 | 뜻 |
|---|---|
| 저장 | 이 서비스에 기록해 다시 열 수 있다. 외부 시스템에는 반영하지 않는다. |
| 검토 | 읽고 확인만 한다. 어떤 값도 바뀌지 않는다. |
| 확정 | 이 서비스 안에서 '확정 준비' 상태로 표시하는 것까지다. 방송사 편성 시스템에는 반영하지 않는다. |
| 내보내기 | 파일(엑셀·Word·PPT)을 내 PC로 내려받는다. 서비스에 기록하지 않는다. |

## 자주 하는 질문

- **'—'가 보여요**: 값이 없다는 뜻이다(미수신·계산 불가). 0이 아니다. 관측된 0은 '0'으로 나온다.
- **'잠정'이 뭐죠**: 공식 주간·월간 파일이 오기 전, 일간 값으로 만든 임시 값이다. 공식 파일이 오면 '확정'으로 바뀐다.
- **같은 날 일간·주간 보고서가 헷갈려요**: 이름·파일명에 '일간/주간/월간 보고서 · 채널 · 기간'과 스냅샷 ID가 들어 있다.
- **AI 문장이 없어요**: 수치 대조를 통과하지 못한 문장은 폐기되고 규칙 기반 문구가 쓰인다. 보고서의 '전제·한계'에 그 사실이 적힌다.
- **'권리 미확인'**: Avail 자료가 없거나 해석이 확인되지 않았다는 뜻이다. 후보를 찾는 것은 되지만 '실행 가능'으로는 표시되지 않는다.
