# 운영 문서

운영자(관리자)와 편성 PD가 일상에서 쓰는 절차만 짧게 모았다. 개발 배경은 `docs/agent-improvement/`에 있고, 여기에는 **무엇을 보고 무엇을 누르는지**만 적는다.

| 문서 | 언제 보나 |
|---|---|
| [운영자 사용 가이드](운영자_사용가이드.md) | 매일 자료 올리기, 화면 읽는 순서, 확인할 것 |
| [지표 사전](지표_사전.md) | 시청률·점유율·도달률·시청시간 비율·순위·지수가 무엇이고 어떻게 표기하나 |
| [데이터 품질 문제 대응](데이터_품질_대응.md) | 자료 수신·반영 현황에 이상이 보일 때 |
| [Avail 매칭과 예약 복원](Avail_매칭과_예약_복원.md) | 권리(Avail) 올리기·콘텐츠 연결·예약 취소와 복원 |
| [모델 승격과 회귀](모델_승격과_회귀.md) | 예측 모델을 바꾸거나 성능이 떨어졌는지 볼 때 |
| [보고서 재발행](보고서_재발행.md) | 보고서가 바뀌어야 할 때, 이전 보고서를 찾을 때 |

원칙 세 가지:

1. **숫자는 DB에서 온 것만** 믿는다. 화면의 AI 문장은 그 숫자를 풀어쓴 것이고, 수치 대조를 통과하지 못하면 자동으로 빠진다.
2. **모르면 모른다고 표시한다.** 데이터 없음·미수신·잠정·권리 미확인은 서로 다른 말이고 0이나 '가능'으로 바뀌지 않는다.
3. **확정은 이 서비스 안의 '확정 준비' 표시까지**다. 방송사 편성 시스템에는 어떤 것도 반영되지 않는다.

점검 결과와 출시 보류 항목은 `docs/agent-improvement/TRACEABILITY.md`, `RELEASE_READINESS.md`에 있다.
