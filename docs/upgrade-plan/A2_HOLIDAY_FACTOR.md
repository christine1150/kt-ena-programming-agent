# A2. 공휴일·연휴 효과 계수 — 결과와 구현 명세 (F-4)

- 작성: 2026-11-13 (고도화 계획 F-4, 설계: Claude Fable)
- 스크립트: `scripts/upgrade-plan/a2-holiday-factor.mts` (읽기 전용) → `docs/upgrade-plan/a2-holiday-factor.json` (실적 포함 — 커밋하지 않음)
- 자료: `public_holidays`(2024~2027 시드, 78일), 자사 닐슨 6채널 KPI 타깃 2025-01~2026-11-09, 운영 엔진(`MetricModel`, 마감 7일 전).

## 0. 결론 한 장

1. **공휴일 효과는 "낮 시간대"에 있고 "저녁"에는 없다.** 평일 하루 공휴일은 08~17시가 평소(같은 요일 ±4주) 대비 1.36~1.49배, 17~20시 1.22배인 반면 20~23시는 0.98배, 23~02시는 0.69배다. 설·추석 연휴의 평일은 낮 1.49~1.66배, 20~23시 0.94배. **연휴 전날·다음 날은 효과가 없다**(중앙값 1.04·0.95, 시간대별로도 1.0 근처). 흔히 말하는 "연휴 전날 저녁 특수"는 이 자료에서 보이지 않는다(전날 23~02시 1.28배만 예외, 표본 작음).
2. **채널 차이**: 설·추석에 ENA 1.84배·ENA Drama 1.57배·ENA Play 1.60배(2049 채널이 크게 오름), OLIFE 1.17배·ONCE 1.09배·ENA Story 0.96배(가구 채널은 작음). 하루 공휴일은 ENA Story 1.33·ENA 1.25·ENA Play 1.22·OLIFE 1.18이고 ENA Drama 0.91·ONCE 0.97은 효과가 없다.
3. **그러나 운영 엔진은 공휴일에 이미 크게 틀리지 않는다.** 2026년 평일 공휴일 방영 1,349건에서 현행 기대값의 평균 편차는 −0.009%p(아주 약간 낮게)뿐이다. 엔진이 프로그램 단위 지수를 쓰고 공휴일 편성(특집·영화·몰아보기)이 그 지수에 반영되므로, "그 요일 자리 평소"로 예측해도 체계적 오차가 작다.
4. **예측 보정은 채택 기준 미달이다.** 그 날짜 이전 공휴일로만 추정한 계수(유형×채널×시간대, 8건↑, 1쪽 수축)를 곱하면 MAE 비율 **0.979 [0.947, 1.012]** 로 구간이 1을 포함한다. 채널별로는 ENA Play 0.922 [0.88, 0.96]만 확실히 낫고 ENA 0.956 [0.90, 1.00]은 경계, 나머지는 1 포함. "공휴일을 일요일 자리로 본다"(1.096)·"토요일 자리"(1.083)는 **확실히 더 나쁘다** — 공휴일은 주말이 아니다(저녁이 다르다). → **예측 보정 플래그는 만들되 기본 off**, ENA Play만 켜는 것은 사후 선택이라 하지 않는다. 설 연휴(2027-02-06~09) 뒤 사례가 늘면 같은 스크립트로 재판정.
5. **보고서·홈 표시는 채택한다.** 수치는 "같은 요일 ±4주 평소 대비 배수"의 중앙값·사례 수로만, 인과가 아닌 참고 정보로 적는다(사용자 지시 2026-08-20 "영향이 있는지 참고로"). 경쟁 채널의 공휴일 편성 변화는 자료(장르·본재 표기)가 부족해 이번에는 넣지 않는다.
6. **2027년 공휴일은 이미 시드돼 있다**(2027-12-27까지, 음력·대체는 "검수 대상"). 채울 것은 없고 **검수·수정 관리자 화면이 없다**(`src/app/admin`에 참조 0건) — 이것이 Sonnet 구현 항목이다.

### 1.4 한계

- 2025~2026 두 해뿐이라 유형별 날짜 수가 14개 안팎이다. 설·추석 외 연휴(long_*)는 1건씩이라 결론 없음.
- 평소 기준(같은 요일 ±4주)에 다른 공휴일·전후일을 뺐지만, 공휴일 특집 편성 자체가 평소와 다른 작품이라 "같은 자리 효과"와 "작품 효과"가 섞여 있다. 엔진 백테스트(§1.3)가 그 둘을 분리한 결과에 가깝다.
- 경쟁 채널 공휴일 편성 변화(특집·영화 비율)는 장르·본재 표기가 없어 이번에 내지 않았다. F2(경쟁 장르 채움) 뒤 가능.
- 대체공휴일·임시공휴일 표기는 시드 그대로이며 검수 전이다.

## 3. 구현 명세 (Sonnet 구간 S-4)

### 3.1 DB (신규 마이그레이션 1개)

- 함수 `holiday_effect_factors(p_channel_code text, p_from date, p_to date)` → (holiday_type, daypart, n_obs, n_days, median_ratio, p25, p75, up_cnt, down_cnt). 계산은 스크립트 §(A)와 같다: 유형 분류(평일 공휴일만; 설·추석/하루/연휴 첫·중간·마지막/전날/다음 날), 시간대별 일 가중 평균 ÷ 같은 요일 ±4주(공휴일·전후일 제외) 중앙값, 평소 3건 이상.
- 함수 `holiday_type_of(p_date date)` → text|null (화면·보고서가 "오늘/내일 공휴일 유형"을 물을 때). 유형 규칙은 위 스크립트 `typeOf`와 한 줄도 다르지 않게 옮기고, 테스트에서 2025~2026 69개 날짜의 유형이 스크립트 결과와 같은지 고정한다.
- `public_holidays`에 `reviewed boolean default false`, `reviewed_by text`, `reviewed_at timestamptz` 열 추가. 시드 행은 false.

### 3.2 서버

- `src/lib/holiday/effect.ts`(읽기): 두 함수 호출 + 1시간 캐시 + 문구 생성 `holidayEffectLine(channel, type, daypart)` → "하루 공휴일 낮(11~14시)은 같은 요일 평소의 1.49배(14일 사례, 편성에 따라 0.9~2.5배)". 사례 8건 미만이면 null.
- 예측 보정 플래그 `expected_kpi.holiday_factor`(기본 false): true면 `features.ts`의 `expected()` 결과에 `holiday_effect_factors` 유형×채널×시간대 중앙값(1쪽 수축, 8건↑)을 곱한다. **기본 off이며 재판정 전에는 켜지 않는다.** 켜면 설정 지문이 바뀌어 제안 캐시가 자동 갱신된다.
- 보고서 스냅샷 `extras.holidayEffect`: 분석 기간에 평일 공휴일·설추석이 있으면 유형별 한 문장 + 그 날의 실제 배수. 웹·Word·PPT 동일 값. 기간에 없으면 단락 없음.

### 3.3 화면

- **관리자 › 공휴일 검수**(신규 `src/app/admin/HolidayManager.tsx`): 연도별 목록(날짜·이름·종류·비고·검수 여부), 행 편집·추가·삭제(삭제는 확인), "검수 완료" 체크 → `reviewed_*` 기록. 2027년 행은 기본 "검수 필요" 배지. API `/api/admin/holidays`(GET/PUT/POST/DELETE, 관리자 권한, `login_log`에 변경 기록).
- **홈 데이터 상태 옆**: 오늘·내일이 평일 공휴일/설추석/전날이면 유형과 채널별 평소 대비 중앙값 한 줄("내일(어린이날) 낮 시간대는 평소의 1.4배 수준이 보통").
- **채널 심층 진단**: 해당 날짜가 공휴일 유형이면 등락 해설에 "공휴일 효과 범위 안/밖" 꼬리표(이미 `weakSlotRemedy`가 공휴일을 원인 후보로 쓰므로 그 문구를 §1.2 수치로 보강).
- **주간·월간 보고서**: "공휴일 영향" 단락(3.2).

### 3.4 테스트

- `npm run test:holiday-effect`(신규): ① `holiday_type_of` 69개 날짜 고정값, ② 효과 함수가 평소 3건 미만 셀을 null로, ③ 8건 미만 문구 null, ④ 플래그 off면 기대값 바이트 동일(골든 9개), ⑤ 관리자 API 권한·검수 기록.
- 푸시 전 `npx tsc --noEmit -p .` 0.

### 3.5 순서(한 커밋에 하나)

1. 마이그레이션(함수 2 + 열 3) + 테스트 ①②
2. `effect.ts` + 홈·채널 심층 문구 + 테스트 ③
3. 관리자 공휴일 검수 화면 + API + 테스트 ⑤
4. 보고서 단락(스냅샷 extras)
5. 예측 보정 플래그(기본 off) + 테스트 ④ — 재판정 전까지 켜지 않음

## 4. 재판정 조건

2027 설 연휴(02-06~09) 실적이 들어온 뒤 `a2-holiday-factor.mts`를 다시 돌려 2026-01~2027-02 평가에서 계수 변형의 95% 구간 전체가 1 미만이면 플래그를 켠다. 채널별로 켜는 것은 그때도 하지 않는다(채널 수만큼의 사후 선택).
