# EBS 「세계테마기행」 회차별 방문 국가·도시 검증 요청

## 역할
당신은 한국 EBS1 다큐 여행 프로그램 **「세계테마기행」**의 방송 정보를 조사하는 리서처입니다. 아래 표의 **각 회차**(EBS 방송 순서 번호 + 방송일 + 부제목)가 **실제로 어느 나라·도시를 다룬 회차인지** 확인해 주세요.

## 배경
- 표는 EBS 세계테마기행 구매 가능 목록(2008~2026, 총 3,317회차) 중, 제가 제목만 보고 나라를 **추정했거나 정하지 못한** 150개 회차입니다.
- "현재 분류"는 검증 대상 가설이며 틀릴 수 있습니다. 가설에 끌려가지 말고 독립적으로 확인하세요.
- 부제목에 있는 "N부"는 한 기획(시리즈)의 N번째 회차입니다. 같은 기획의 부마다 나라가 다를 수 있습니다(예: 인도차이나 3국, 메콩 강, 발칸반도).

## 확인 방법 (우선순위)
1. EBS 공식 프로그램 페이지/다시보기/VOD 회차 소개문("세계테마기행 + 기획명 + N부")
2. 네이버·다음 TV 정보, 방송 보도자료·기사(위키트리, 한국경제TV 등)
3. 확인 못 하면 추측하지 말고 **"확인 불가"** 로 표기

## 출력 형식 (CSV, 한 회차 한 줄, 따옴표로 감싸기)
`순서,방송일,국가(복수면 ;로 구분),도시·지역·주요 장소(;로 구분),확신도(확인됨/유력/확인 불가),근거(출처 URL 또는 소개문 한 줄),현재 분류가 맞는지(맞음/틀림/일부)`

- 국가는 한국어 국가명(예: 키르기스스탄, 튀르키예, 미국)으로 적고, 자치령·지역은 소속 국가를 함께 적어 주세요.
- 부 단위로 나라가 갈리면 **부마다 따로** 적어 주세요.
- 아래 "현재 분류"가 비어 있는 "미정" 회차에 특히 신경 써 주세요.

## 특히 궁금한 점
1. 같은 기획 안에서 부별로 나라·도시가 어떻게 나뉘는지 (예: 2,000km 대장정 메콩을 가다 / 인도차이나 3국 / 삶의 모자이크 발칸반도 / 공존의 강 도나우 / 신세계의 발견 흑해).
2. 제목에 나라 이름이 없는 기획의 실제 촬영지 (예: 마지막 원시 파푸아 — 인도네시아 서파푸아인지 파푸아뉴기니인지, 황금빛 땅 벵골만 — 방글라데시인지 인도인지, 미지의 섬을 찾아서 2~3부, 스페셜로드 경이로운 지구의 유혹 5편).
3. 아시아 최후의 정글, 노마드 아시아(아시안 하이웨이 7), 중앙아시아 고원기행처럼 지역명만 있는 기획의 구체 국가.
4. 방송 후 같은 영상이 제목을 바꿔 재편성된 경우(재방/재편집)가 있는지.
